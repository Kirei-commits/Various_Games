# ぐんぐん農園 — GUNGUN FARM

待ち時間の長い農園ゲームから、**待ち時間だけを抜いたもの**。
いちばん長い作物でも9秒、いちばん手の込んだ加工品でも10秒で出来上がる。

さらに、**まとめてまいた畑は順番に実る**。一斉に実って一斉に空くと
「全部タップ → 数秒なにもできない」の繰り返しになるので、時間差でずらしてある。
おかげで**いつ見てもどこかが光っていて、手が止まらない**
（1秒以上の待ちは全体の 0.1%。`npm run simulate` が毎回測っている）。

ブラウザで `index.html` を開けばそのまま遊べる。サーバーもビルドも要らない。

```
https://kirei-commits.github.io/Various_Games/gungun-farm/
```

## 遊びかた

畑の操作は、下の大きい2つのボタンだけで回る。

| ボタン | やること |
| --- | --- |
| 🧺 **しゅうかく** | 実ったものを収穫して、**選んでいるタネをその場に植え直す** |
| 🏭 **ぜんぶ仕込む** | 出来たものを取り出して、余っている材料で全部仕込む |

「収穫してから植え直す」の往復は、**待ちの無いこのゲームでは判断が無い**ので
1タップに畳んである（[経緯](./ROADMAP.md#自己レビューと市場調査でわかったこと2026-09-13)）。
まとめ仕込みは、**注文が欲しがっている材料には手を出さない**。

考えるところは下の段にある。

1. **たね** — 何を植えるか。切り替えると、次の収穫からそれが植わる
2. **こうぼう** — 1台ずつ押せば、注文ぶんを割ってでも仕込める
3. **ちゅうもん** — 届けるとコインと経験値。早いほどオマケ、続けるほど倍率。いらない注文は断れる。
   レベル7から **ふなびん**（下記）も来る
4. **みせ** — 売って、倉庫を広げて、機械と畑を増やす

倉庫がいっぱいだと収穫も取り出しもできない。売るか、広げる。

### 2つのモード

| モード | 中身 |
| --- | --- |
| のんびり | 終わりなし。閉じても続きから再開できる |
| 3分チャレンジ | 180秒で稼いだコインを競う。記録が残る |

## 何を植えるかは、取引になっている

**短い作物ほど1秒あたり稼ぎ、長い作物ほど倉庫1枠の値打ちが高い。**
時間差まきのおかげで、長い作物は実る間隔も空く——つまり**手が空く**。

| 作物 | 秒 | タネ代→売値 | 1秒あたり | 解放 |
| --- | ---: | ---: | ---: | ---: |
| こむぎ | 2 | 3 → 11 | **4.00** | Lv1 |
| にんじん | 3 | 5 → 16 | 3.67 | Lv1 |
| とうもろこし | 4 | 7 → 21 | 3.50 | Lv2 |
| だいず | 5 | 10 → 26 | 3.20 | Lv4 |
| さとうきび | 6 | 14 → 32 | 3.00 | Lv6 |
| いちご | 7 | 17 → 35 | 2.57 | Lv8 |
| かぼちゃ | 8 | 21 → 40 | 2.38 | Lv10 |
| ぶどう | 9 | 26 → 45 | 2.11 | Lv12 |
| トマト | 9 | 42 → 61 | 2.11 | Lv14 |
| オリーブ | 9 | 56 → 75 | 2.11 | Lv16 |
| メロン | 9 | 72 → **91** | 2.11 | Lv18 |

同じ手順で作物だけ変えて10分回すと、こうなる。

| 作戦 | 稼ぎ | 経験値 | 収穫の手数 |
| --- | ---: | ---: | ---: |
| 短いのだけ | 48,407 | 6,009 | **3,000回** |
| 長いのだけ | 37,902 | 6,772 | **800回** |

**どちらも全部では勝たない。** 手が空いているなら短いのを回して稼ぐ。
工房と注文に手を掛けたいなら長いのを植えて放っておく。
`tests/logic/economy.test.mjs` が、この取引が崩れていないかを毎回確かめている。

## ふなびん — 余ったものの行き先

待ち時間の無い農園は、**ふつうの注文が吸えるよりずっと多く産む**。
測ったら、稼ぎの55%が「余りを売っただけ」だった。

そこでレベル7から **ふなびん** が来る。ふつうの注文との違いは3つ。

- **少しずつ積める。** 揃うまで抱えておかなくていいので、余ったそばから積める
- **安いものをたくさん運ぶ。** 船が運ぶのは余り物（深い加工品を大量に頼まない）
- **積みきると報酬が2.2倍**（ふつうの注文は1.35倍）

出港に間に合わなくても、**積んだぶんは売値で引き取られる**ので損はしない。

| コインの出どころ（10分） | ふなびん導入前 | 導入後 |
| --- | ---: | ---: |
| ふつうの注文 | 44.6% | 40.3% |
| ふなびん | — | 25.5% |
| **注文ぜんぶ** | **44.6%** | **65.8%** |
| 余りを売る | 55.4% | **34.2%** |

船は「何を植えるか」の理由にもなる。大量に要るものへ畑を向けると一気に進む。

## 作るもの

施設は Lv1 のせいふんきから始まり、作った品をさらに材料にして鎖が伸びていく。
ピザ（Lv17）は こむぎこ + チーズ + ケチャップ の4段目。
レベルが上がるたびに、**作物か施設のどちらかが必ず増える**（Lv20 で作物11種・施設18台・品物29種）。

加工にかかるのは 3〜10秒。いちばん手の込んだパイでちょうど10秒。

この上限は `tests/lint.mjs` が機械的に見張っている。11秒の作物は追加できない。
**「何も解放されないレベルが2つ以上つづくこと」も lint が弾く**
（一度 Lv14〜20 の7レベルが空っぽになっていた）。

## 開発

```bash
npm ci && npm test     # lint → ロジック → E2E
npm start              # http://127.0.0.1:8082/
npm run simulate       # 実際の秒数ぶん遊んで、育ちの速さと詰みの有無を測る
npm run playtest       # 実ブラウザで、画面のボタンだけを押して回してみる
```

設計上の制約と、過去に踏んだ失敗は [CLAUDE.md](./CLAUDE.md) にある。**触る前に読むこと。**

### URLで渡せるもの（テストと再現用）

| パラメータ | 意味 |
| --- | --- |
| `?seed=7` | 注文の引きを固定する |
| `?speed=8` | 時間の倍率。待たずに確かめたいとき |
| `?mode=rush&limit=60000` | 3分チャレンジ（長さも変えられる） |
| `?fresh=1` | 保存された農園を読み込まない |
| `?sound=off` `?help=off` | 音・初回の説明を止める |
