# ぐんぐん農園 — GUNGUN FARM

待ち時間の長い農園ゲームから、**待ち時間だけを抜いたもの**。
いちばん長い作物でも9秒、いちばん手の込んだ加工品でも10秒で出来上がる。

ブラウザで `index.html` を開けばそのまま遊べる。サーバーもビルドも要らない。

```
https://kirei-commits.github.io/Various_Games/gungun-farm/
```

## 遊びかた

1. **たね** をえらんで、畑をタップ。育ったらもう一度タップで収穫
2. **こうぼう** は材料がそろうとタップで仕込める。出来たらもう一度タップで倉庫へ
3. **ちゅうもん** を届けるとコインと経験値。早いほどオマケがつき、続けるほど倍率が上がる
4. **みせ** で売って、倉庫を広げて、機械と畑を増やす

倉庫がいっぱいだと収穫も取り出しもできない。売るか、広げる。

主な操作は下の大きい2つのボタン（**ぜんぶ収穫 / ぜんぶ植える**）に寄せてある。
1マスずつ押さなくても回るので、指が疲れず、誤タップも減る。

### 2つのモード

| モード | 中身 |
| --- | --- |
| のんびり | 終わりなし。閉じても続きから再開できる |
| 3分チャレンジ | 180秒で稼いだコインを競う。記録が残る |

この上限は `tests/lint.mjs` が機械的に見張っている。11秒の作物は追加できない。

## 開発

```bash
npm ci && npm test     # lint → ロジック → E2E
npm start              # http://127.0.0.1:8082/
npm run simulate       # 実際の秒数ぶん遊んで、育ちの速さと詰みの有無を測る
npm run playtest       # 実ブラウザで、画面のボタンだけを押して回してみる
```

設計上の制約と、過去に踏んだ失敗は [CLAUDE.md](./CLAUDE.md) にある。**触る前に読むこと。**

### URLで渡せるもの（テストと再現用）

| パラメータ | 意味 |
| --- | --- |
| `?seed=7` | 注文の引きを固定する |
| `?speed=8` | 時間の倍率。待たずに確かめたいとき |
| `?mode=rush&limit=60000` | 3分チャレンジ（長さも変えられる） |
| `?fresh=1` | 保存された農園を読み込まない |
| `?sound=off` `?help=off` | 音・初回の説明を止める |
