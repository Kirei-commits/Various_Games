# ぐんぐん農園 — つぎにやること

迷ったら **「待ち時間が増えていないか」「1画面から溢れていないか」** で決める。
この2つを守れないものは、どれだけ面白くても入れない。

数値を触ったら `npm run simulate` で測り直し、`tests/logic/economy.test.mjs` の
閾値も更新する（**実測より下に置く**）。

## A. 手触り（優先）

1. **人が遊んだときのペースを測って直す。**
   シミュレーション（上手な回し方）は10分でレベル14だが、実ブラウザの通しプレイは
   3分でレベル4。差が大きい。一括操作をもう一段楽にするか、序盤の経験値を厚くするか、
   **測ってから**決める
2. **畑の「まとめて仕込む」。** こうぼうを1タップで満杯まで仕込めるようにする
   （いまは1回ずつ。材料があるときの連打がつらい）
3. **注文の中身をもう少し読みやすく。** いまは絵文字と数だけ。
   持っていない品を目立たせる／作り方をたどれるようにする

## B. 遊びの幅

4. **とくべつ注文（トラック便）。** 期限が短いかわりに報酬が大きい1枠を、たまに混ぜる
5. **かざり。** 農園に置けるだけのもの。コインの行き先を増やす（能力は上げない）
6. **デイリー。** 「きょうの作物」に倍率。1日1回だけ、短く来る理由を作る
7. **実績。** 「10コンボ」「ぜんぶの機械をそろえる」など、目標を見せる

## C. 見た目と音

8. **収穫の手応え。** いまは絵文字が飛ぶだけ。軌跡と倉庫への吸い込みを足す
9. **時間帯で空の色を変える。** ゲーム内の経過で朝→昼→夕。待たせないので変化が速い
10. **BGM。** Web Audio で短いループを合成する（音源ファイルは持ち込まない）

## D. 仕組み

11. **オフラインでも開ける（Service Worker）。** 実行時依存ゼロのまま、初回以降を速くする
12. **記録の見える化。** 最高記録だけでなく、直近5回の3分チャレンジを並べる

## やらないと決めたこと

- **課金で待ち時間を飛ばす仕組み。** 元のゲームの待ち時間を消したのが出発点なので、
  「待ちを金で買う」構造そのものを持ち込まない
- **自動で収穫・自動で売る。** 資源のやりくりが消えて、畑を眺めるだけになる
- **10秒を超える作物・加工品。** どんなに強くても入れない
