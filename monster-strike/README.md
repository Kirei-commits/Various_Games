# ひっぱりストライク（HIPPARI STRIKE）

キャラを引っぱって離すと飛んでいき、敵にぶつけて倒すひっぱりアクション（モンスト風）。
`index.html` ひとつで動きます（ビルド不要・実行時の依存ゼロ・画像ファイルなし。絵はすべて Canvas で描画）。

## 遊び方

- 画面を押して**引っぱり、離すと発射**。引いた向きの逆へ飛びます。
- 遠くまで引くほど強く、一定以上は頭打ち。引きを戻して離すと**キャンセル**（ターンは消費しない）。
- 引っぱっている間は、**予測軌道**（反射2回ぶんまで）と強さの矢印が出ます。
- 止まるまでが1ターン。順番は A → B → C（キャラを押せば交代もできる）。
- 動いているキャラが止まっている**味方に当たる（貫通なら通り抜ける）と、その味方の友情コンボ**が出ます。1ショットにつき味方1体1回。
- 敵の左上の数字は**攻撃までのターン数**。0になった敵がチームのHPを削ってきます。
- 敵を全滅させると次のウェーブへ。最後のボスを倒せばクリア、チームのHPが0になると負け。
- ボスの**光る弱点**に当てると**3倍**のダメージ。

## ステージ「はじまりの洞窟」

| ウェーブ | 敵 | HP | 攻撃 |
| --- | --- | --- | --- |
| 1 | スライム ×2（円） | 7000 | 単体 2000（3・4ターンごと） |
| 1 | ブロックゴーレム（矩形） | 12000 | 全体 3500（3ターンごと） |
| 2 | レッドドラゴン（ボス・弱点あり） | 55000 | 全体 6000（3ターンごと） |
| 2 | コウモリ ×2（円） | 5000 | 単体 1500（2・3ターンごと） |

チームのHPは 28000。
数値は自動プレイで測って決めています（上手な先読みなら10ターンでクリア、ふつうの腕前で勝率7割ほど。
友情コンボを使わないと、ふつうの腕前の勝率は 5% まで落ちます）。

| キャラ | 撃種 | 攻撃力 | 友情コンボ |
| --- | --- | --- | --- |
| A（青） | 反射 | 1500 | **ホーミング**：6発の弾が近い敵から順に飛ぶ（1発 500） |
| B（赤） | 貫通 | 1800 | **クロスレーザー**：B を通る縦・横のビーム。線上の敵に 1800 |
| C（金） | 反射 | 1300 | **爆発**：C のまわり半径150の敵に 2500 |

- **反射**：壁・キャラ・敵に当たると**入射角のまま鏡映しに**跳ね返る。当たるたびに速さが 84% に落ちる。敵と壁の間で何度も跳ねると大ダメージ
- **貫通**：キャラや敵を**すり抜ける**。突入の瞬間に速さが 70% に落ち、通り抜けている間は摩擦が 2.5 倍。弱点を通り抜けると突入ぶん＋3倍

壁に当たると、どちらも速さが 88% に落ちます。
右上の「調整」で、初速・摩擦・反発係数・貫通の減速をその場で変えられます。

## 開発

```bash
npm ci
npm start          # http://127.0.0.1:8084/
npm run lint
npm run test:logic # 物理・戦闘・バランス（Node だけで動く）
npm run test:e2e   # ブラウザ（desktop + mobile）
```
