# ひっぱりストライク（HIPPARI STRIKE）

キャラを引っぱって離すと飛んでいく、ひっぱりアクション（モンスト風）。
`index.html` ひとつで動きます（ビルド不要・実行時の依存ゼロ・画像ファイルなし。絵はすべて Canvas で描画）。

## 遊び方

- 画面を押して**引っぱり、離すと発射**。引いた向きの逆へ飛びます。
- 遠くまで引くほど強く、一定以上は頭打ち。引きを戻して離すと**キャンセル**（ターンは消費しない）。
- 引っぱっている間は、**予測軌道**（反射2回ぶんまで）と強さの矢印が出ます。
- 止まるまでが1ターン。次は自動でもう一方のキャラの番になります（キャラを押せば交代もできる）。

| キャラ | 撃種 | 動き |
| --- | --- | --- |
| A（青） | 反射 | 壁・キャラ・的に当たると**入射角のまま鏡映しに**跳ね返る。当たるたびに速さが 84% に落ちる |
| B（赤） | 貫通 | キャラや的を**すり抜ける**。突入の瞬間に速さが 70% に落ち、通り抜けている間は摩擦が 2.5 倍 |

壁に当たると、どちらも速さが 88% に落ちます。
右上の「調整」で、初速・摩擦・反発係数・貫通の減速をその場で変えられます。

## 開発

```bash
npm ci
npm start          # http://127.0.0.1:8084/
npm run lint
npm run test:logic # 物理（Node だけで動く）
npm run test:e2e   # ブラウザ（desktop + mobile）
```
