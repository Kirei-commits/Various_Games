# サクサク爽快アップデート 企画書

## 目的

「引っぱって離す → ガンガン当たって敵が弾け飛ぶ → すぐ次が撃てる」の気持ちよさを強くする。
**戦闘の計算（物理・ダメージ・難しさ）は1つも変えない。** 見せ方と待ち時間だけを変えるので、
難しさのテスト（balance）はそのまま通る。

## 調べたこと（今の版を数字で測った）

ステージ1〜5で、全力のショットを向きを変えて200回撃った（`tests/logic` の物理と戦闘をそのまま使用）。

| 測ったもの | 値 |
|---|---|
| 1ショットの長さ | 平均 **3.4秒** |
| そのうち、速さ350未満でのろのろ転がっている時間 | 平均 **1.6秒**（全体の約半分） |
| 最後に敵に当たってから止まるまで | 平均 **1.9秒** |
| 止まってから次に撃てるまで（敵の攻撃が無いとき） | 0.35秒 |
| 敵1体の攻撃の演出 | 1.07秒 |
| ウェーブが変わるときの待ち | 1.4秒 |

足りないもの:

1. **テンポ**: 1ショットの後半は「もう何も起きない転がり」を見ているだけ。敵を全部倒した後も止まるまで待たされる。
2. **当たりの手応え**: HIT の数字は出ているが、増えても数字が変わるだけで盛り上がらない。音は何発目でも同じ高さ。
3. **倒したときの気持ちよさ**: ザコを倒しても、少し光って消えるだけ。ウェーブの最後の1体を倒しても特別な演出が無い。
4. **ショットの結果が残らない**: 1発でどれだけ稼いだかが、止まると消えてしまう。
5. **引っぱる手触り**: 強く引いても音も振動も無く、どれだけ溜まったか体で分からない。
6. **敵のHPの減り方**: バーが一瞬で縮むので、どれだけ削ったかが目に残らない。

## やること

### A. テンポ（サクサク）

| # | 内容 |
|---|---|
| A1 | **失速したら自動で早送り**: 動いているキャラが遅くなったら（速さ380未満）、時間を最大2.4倍まで滑らかに速くする。友情の弾が飛んでいる間・ヒットストップ中はしない。画面の左上に「▶▶」 |
| A2 | **ウェーブの敵を全部倒したら即早送り**: 残りの転がりは3.5倍速 |
| A3 | **待ち時間を短く**: 止まってから 0.35→0.2秒、敵の攻撃 1.07→0.8秒、ウェーブの切り替え 1.4→1.1秒 |
| A4 | **⏩ 倍速ボタン**（フィールドの左下）: 押すたびに ×1 ⇔ ×2。引っぱっている間とゲージは速くならない。ブラウザに覚える |

時間を速くしても、物理は同じ 1/240秒の刻みで同じ回数だけ進むので、**結果はまったく同じ**（早送りで当たり方が変わらない）。

### B. 当たりの手応え

| # | 内容 |
|---|---|
| B1 | **HIT カウンターが弾む**: 当たるたびに大きくなって戻る。10 HIT で金、20 HIT で虹色 |
| B2 | **連続ヒットで音程が上がる**: 1ショットの中で当たるほど高い音に（最大で約2倍の高さ） |
| B3 | **10・20・30… HIT の節目**で、短いファンファーレと光の輪 |
| B4 | **敵のHPバーに「遅れて減る白いバー」**: 削った分が一瞬残ってから縮む（ボスのバーも） |

### C. 倒したときの気持ちよさ

| # | 内容 |
|---|---|
| C1 | **撃破で破片が飛び散る**（敵の色の三角形が回りながら落ちる）＋画面が一瞬白く光る |
| C2 | **ウェーブの最後の1体はラストヒット演出**: 0.5秒のスロー＋「CLEAR!」 |
| C3 | **ショットの結果**: 止まったら「12 HIT 34,567」と評価（GOOD / GREAT / EXCELLENT / AMAZING）を出す |
| C4 | 撃破・弱点・SS で**スマホが短く震える**（震えに対応している端末だけ。音を OFF にすると震えも止まる） |

### D. 引っぱる手触り

| # | 内容 |
|---|---|
| D1 | 引く強さが 25%・50%・75%・最大を超えるたびに、だんだん高くなる「カチッ」という音と小さな振動 |
| D2 | 最大まで引いたら、予測線が金色に光る |

### E. 速さの見た目

| # | 内容 |
|---|---|
| E1 | 速いほど残像が長く、太くなる |

## やらないこと

- 物理（反発・摩擦）や敵のHPは変えない（難しさのテストの前提が崩れるため）。
  反発を上げてヒット数を増やす案も測ったが、0.84→0.96 にしても1ショット 2.9→3.5ヒットで、効果が小さい割に難しさが変わる。
- モンストの絵・音・名前は使わない。

## 確かめ方

- `npm run lint && npm run test:logic && npm run test:e2e`（今までのテストがそのまま通る＝結果が変わっていない）
- 新しい E2E: 倍速ボタンの切り替えと記憶、早送りが働くこと、ショットの結果の表示
- 1ショットの長さを測り直す（画面の時間で）

## 結果（実装後に測った値）

ステージ1で同じ8通りの引き方をして、「離してから次に撃てるまで」の時間（敵の攻撃・ウェーブの切り替えを含む）を
ブラウザで測った。物理の結果は同じなので、当たり方・ダメージは前と完全に一致する。

| | 平均 | 8回の内訳（秒） |
|---|---|---|
| 前の版 | **5.15秒** | 4.4 4.3 7.5 4.7 4.3 6.5 3.3 6.1 |
| 今回（×1） | **3.95秒**（−23%） | 3.4 3.9 5.9 3.4 3.2 4.9 2.3 4.6 |
| 今回（×2） | **2.18秒**（−58%） | 1.8 2.3 3.2 1.9 1.7 2.6 1.3 2.6 |
