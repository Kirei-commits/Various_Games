# パズドラ（パズル&ドラゴンズ）調査と、ミニゲーム「ドロップパズル」の設計

2026-09-30 作成。ひっぱりストライクの中に、パズドラの遊び方を参考にしたミニゲームを作るための調査です。
名前・キャラ・絵・音はガンホーの権利なので使いません。仕組み（盤面・ドロップ・コンボの倍率）だけを参考にし、
キャラはこのゲームの12体を使います。

## 1. パズドラとは

| 項目 | 内容 |
| --- | --- |
| 正式名称 | パズル&ドラゴンズ（略称: パズドラ） |
| ジャンル | パズルRPG。モンスターを育て、パズルでバトルする |
| 運営 | ガンホー・オンライン・エンターテイメント |
| 配信開始 | iOS 2012年2月20日、Android 2012年9月18日 |

モンスターでチームを組んでダンジョンに入り、盤面のドロップをそろえて消すと、同じ属性のモンスターが敵を攻撃します。

## 2. パズルのルール（調べた仕様）

| 項目 | 仕様 | 出典 |
| --- | --- | --- |
| 盤面 | 6×5 の30マス | 検索結果（のあ note・ゲームエイトほか） |
| ドロップ | 火・水・木・光・闇・回復の6種類 | 同上 |
| 操作 | ドロップを1つつかんで盤面を自由に動かす。通った所のドロップと入れ替わる | 同上 |
| 操作時間 | 基本 5秒（2018年2月の Ver.13.0 で 4秒から延長） | ファミ通App |
| 消える条件 | 同じドロップを縦か横に3個以上つなげる | 同上 |
| 落ちコン | 消えた所に上からドロップが落ち、新しいドロップが降ってくる。そこでそろえば追加のコンボ | 同上 |
| 最大コンボ | 通常盤面なら組んで最大10コンボ | 同上 |
| 属性相性 | 火→木→水→火は有利2倍・不利0.5倍、光と闇はお互いに2倍（不利なし） | ゲームエイト |
| 先制攻撃 | フロアに入ったとき、最初のターンだけ敵が先に動くことがある | ゲームエイト |

### ダメージと回復の計算

```text
攻撃 = 攻撃力 × リーダー倍率 × (1 + 0.25 × (消したドロップ数 − 3)) × (1 + 0.25 × (コンボ数 − 1)) × 属性相性
回復 = 回復力 × (1 + 0.25 × (消した回復ドロップ数 − 3)) × (1 + 0.25 × (コンボ数 − 1))
```

- 5コンボで2倍、8コンボで2.75倍、10コンボで3.25倍（コンボ倍率）
- 4個消しは1.25倍、5個消しは1.5倍（ドロップ数の倍率）
- 出典: ゲームエイト（ダメージ計算・回復力の計算）

## 3. ミニゲーム「ドロップパズル」の設計

パズドラの仕組みをもとに、1ファイル・短時間で遊べる形にします。

| 項目 | このゲームでの決まり |
| --- | --- |
| 盤面 | 6×5。ドロップは 火・水・木・光・闇・回復 の6種類。最初の盤面に「そろった所」は作らない |
| 操作 | ドロップを押して引きずる。通った隣のマス（斜めも含む）と入れ替わる。最初に入れ替えてから **5秒**、または指を離したら終わり |
| 消える条件 | 縦か横に3個以上。つながった同じ色のドロップはまとめて1コンボ |
| 落ちコン | 消えた所に上から落ち、空いた所に新しいドロップが降る（乱数は外から渡す）。そろわなくなるまで続ける |
| チーム | 編成中の4体。先頭のキャラがリーダー（同じ属性の攻撃が1.5倍） |
| 攻撃 | 消した色と同じ属性のキャラが攻撃。上の式でダメージ。5個以上つなげて消すと全体攻撃、それ以外は先頭の敵 |
| 回復 | 回復ドロップで回復。回復力はキャラの HP の 1/20 |
| 属性相性 | パズドラと同じ 2倍 / 0.5倍（光⇔闇は2倍） |
| 敵 | 3フロア。敵には攻撃までのターン数があり、0 になると攻撃する。チームの HP が 0 で負け |
| 報酬 | クリアでジェム（初回 20、2回目から 8、負けても 2） |

### 難しさ（2026-09-30 測定。tests/logic/puzzle.test.mjs）

最初の4体で、毎ターン k コンボ（色はでたらめ、2割は4〜5個消し）するプレイヤーを200回ずつ試した。
敵の HP と攻撃力は、最初の案から HP 0.7倍・攻撃 2倍にした（最初の案では3コンボでも 99.5% 勝てた）。

| 毎ターンのコンボ | 勝率 | 勝ったときの平均ターン |
| --- | --- | --- |
| 1 | 0.00 | - |
| 2 | 0.00 | - |
| 3 | 0.65 | 14.5 |
| 4 | 1.00 | 10.7 |
| 5 | 1.00 | 8.1 |

### モジュールの分け方

- `ms-puzzle`（純粋。乱数は引数でもらう）: 盤面の生成、入れ替え、そろった所の検出、消去・落下・補充、ダメージと回復の計算、敵の行動
- 画面（`ms-game`）: ドロップの描画、引きずる操作、消えて落ちる演出、コンボの数、ダメージの数字
