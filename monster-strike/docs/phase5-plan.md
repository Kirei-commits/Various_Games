# ひっぱりストライク フェーズ5〜8 実装計画

2026-09-29 作成。攻略サイトと公式サイトを直接読んで集めた仕様をもとに、次に作るものを決めた計画です。
数値の出典は各章の末尾にあります。サイトに載っていなかった数値は「自前で決める」と書き、自動プレイで測って決めます。

## 0. 方針

- **1ファイル・ビルド不要・実行時依存ゼロは変えない。** サーバーを使う機能（アカウント・ガチャ・課金・マルチ）はこのゲームでは作らない（10章）。
- **物理と戦闘の分け方を守る。** 動きを変えるもの（ワープ・ブロック・減速壁・SSの加速）は物理、HPやダメージを変えるもの（属性・キラー・地雷・魔法陣・ハート）は戦闘。
- **名前はオリジナルにする。** 「獣神化」「わくわくの実」などゲーム固有の用語は使わない。画面の表記は「必殺技」「ギミック」など一般的な言葉にする。
- 各フェーズの終わりに `balance.test.mjs` の期待値を測り直してコミットに理由を残す。

| フェーズ | 内容 | 主に触るスクリプト |

## 1. フェーズ5：属性・キラー・4体編成

### 1-1. 調べた仕様

| 項目 | 仕様 | 出典 |
| --- | --- | --- |
| 属性 | 火・水・木・光・闇。火→木→水→火の三すくみ、光と闇はお互いに有利 | ゲームエイト |
| 有利属性で殴る | 約1.33倍 | ゲームエイト |
| 不利属性で殴る | 約0.66倍 | ゲームエイト |
| 有利属性から受ける | 約0.66倍（不利属性からは約1.33倍） | ゲームエイト |
| 属性効果アップ | 与1.5倍・被0.5倍（超：2.0倍・0.33倍） | ゲームエイト |
| 属性×弱点 | 掛け算（1.33 × 3 ≒ 4倍） | ゲームエイト |
| 友情コンボ | 無属性の友情は属性倍率がかからない（等倍） | ゲームエイト |
| キラー | S 1.25 / 無印 1.5 / M 2.0 / L 2.5 / EL 3.0 倍 | ゲームエイト・ゲームウィズ |
| キラーの適用 | 素のアビリティなら直殴り・友情・SSすべてに乗る | ゲームウィズ |
| 敵のキラー | ボスがキラーを持つと、対象の味方が受けるダメージが増える | ゲームウィズ |
| 属性耐性 | 無印25%・M50%軽減（無属性攻撃には効かない） | ゲームウィズ |
| 底力 | HP50%未満で攻撃力1.5倍（Mは2倍） | ゲームウィズ |

### 1-2. 作るもの

**ダメージ計算を1か所にまとめる**（`Battle._hitDamage(unit, enemy, opts)`）。いまは `atk × 弱点` を `apply()` と `_combo()` にそれぞれ書いているので、フェーズ5の最初にこの関数へ寄せる。

```text
直殴り = 攻撃力 × 弱点(3) × 属性(1.33 / 1 / 0.66) × キラー × 一時強化（SS・超ADW・剣など）
友情   = 友情の威力 × 属性（友情に属性がある場合だけ） × キラー × 一時強化（友情に乗るものだけ）
被ダメ = 敵の攻撃力 × 属性（受ける側） × (1 − 耐性)
```

- 倍率はすべて `opts` の配列で返し、画面は「弱点×3」「有利×1.33」「キラー×1.5」のように内訳を出せるようにする。
- 端数は最後に1回だけ `Math.round`（途中で丸めると自動プレイと画面で差が出る）。

**データの追加**（`ms-data`）

| 対象 | 追加するフィールド |
| --- | --- |
| キャラ | `element`、`hp`（キャラごとのHP）、`killers: [{ race: 'dragon', rate: 1.5 }]`、`resist` |
| 敵 | `element`、`race`（dragon / slime / golem / beast） |
| 友情コンボ | `element`（省略時は無属性） |
| 敵の攻撃 | `single` は近い味方の属性で倍率を決める。`all` は味方ごとに計算して合計 |

**チームHP**：キャラごとの `hp` の合計にする（公式の仕様どおり。フェーズ8のハートの回復量がキャラの最大HPで決まるため）。

**4体編成**：キャラ D を足して A→B→C→D の順にする。編成画面は作らず、データで4体を定義する。

| キャラ | 撃種 | 属性（案） | アビリティ（案） | 友情（案） |
| --- | --- | --- | --- | --- |
| A | 反射 | 水 | ADW | ホーミング（無属性） |
| B | 貫通 | 火 | AGB・ドラゴンキラー | クロスレーザー（火属性） |
| C | 反射 | 木 | 底力 | 爆発（無属性） |
| D（新） | 貫通 | 光 | マインスイーパー（フェーズ7） | 拡散弾（無属性）※副友情の試験台 |

### 1-3. 実装の結果（2026-09-29）

計画から変えた点と、測って決めた数値です。

- 敵の属性：スライムは木、ゴーレムは水、ドラゴンは火、コウモリは闇。どの敵にも有利なキャラが1体いる（B→スライム、C→ゴーレム、A→ドラゴン、D→コウモリ）。
- 全体攻撃は、攻撃力を4体に割って1体ずつ属性で計算する（属性の差がなければ合計は以前と同じ）。
- 4体になって友情コンボが増え、ふつうのプレイヤーの勝率が0.75から0.91に上がった。ドラゴンのHPを55000→58000、ダメージウォールを800→1400・1000→1800にして0.79に戻した。
- 属性とキラーを外すと勝率は0.57に下がる（属性を考える意味がある）。
- D の友情は「拡散弾」（8方向・1発700・射程420）。D の耐性は闇25%。副友情は作っていない。

### 1-4. テスト

- `battle.test.mjs`：属性表の全25通り、キラー × 弱点 × 属性の掛け算、無属性友情に属性が乗らないこと、耐性。
- `balance.test.mjs`：4体になってターンの回り方が変わるので測り直す。

## 2. フェーズ6：ストライクショット（SS）

### 2-1. 調べた仕様

| 項目 | 仕様 | 出典 |
| --- | --- | --- |
| 発動 | 決まったターン数がたつと使える。画面下のキャラアイコンをタップして発動 | ゲームエイト |
| ターンの減り方 | **誰が撃っても1ショットごとに1減る**（4体なら1巡で4減る）。そのため「SSターン÷4の余り」で最適な手番が決まる | ゲームウィズ（ブログ記事） |
| 使った後 | また同じターン数を待つ | ゲームエイト |
| SSターン短縮 | 触れた味方1体につき自分のSSが1ターン短縮。超SS短縮は 1触れ1・2触れ3・3触れ6 | ゲームウィズ |
| 魔法陣 | ひよこ状態の間はSSを使えない | アルテマ・ゲームウィズ |

### 2-2. 作るもの

- `battle.units[id].ss = { turns, left }`。`endTurn()` で**全員の** `left` を1減らす（0で止める）。
- 撃つ前にキャラのアイコン（または「必殺」ボタン）を押すと、次の一発がSSになる。`left > 0` なら押せない。
- SSの中身は**物理に渡す値**と**戦闘に渡す値**に分けて定義する。

```js
ss: { turns: 12, name: 'ブースト', launch: { speed: 1.6, friction: 0.6 }, battle: { atk: 1.0 } }
ss: { turns: 16, name: '全力',     launch: {},                            battle: { atk: 2.5 } }
ss: { turns: 20, name: 'メテオ',   launch: {},                            battle: { onStop: { kind: 'blast', power: 9000, radius: 220 } } }
```

  - `launch` は `World.launch()` の初速倍率・このショットだけの摩擦倍率。予測軌道も同じ値で回す（約束ごと5）。
  - `battle.atk` はこのショットの間だけの攻撃力倍率（`_hitDamage` の一時強化）。
  - `onStop` は止まったときに出る攻撃。友情コンボの仕組み（`_combo` と `drainCombos`）を流用する。

| キャラ | SS（案） | ターン |
| --- | --- | --- |
| A | ブースト（加速＋摩擦減。壁カンの回数を増やす） | 12 |
| B | 全力（攻撃力2.5倍。弱点貫通でボスを削る） | 16 |
| C | メテオ（止まった位置で大爆発） | 20 |
| D | 仲間呼び（触れた味方の友情が2回出る） | 14 |

- ターン数の余りが1体ずつずれる（12÷4=0、16÷4=0 …）と全員が同じ周で溜まる。4で割った余りを散らした値を最終的に選ぶ。
- SSターン短縮は C のアビリティにする（触れた味方の数で短縮）。

### 2-3. 自動プレイ

- 先読みの候補に「SSあり」を足す（SSが溜まっているときだけ）。上手なプレイヤーが「ボス戦まで取っておく」判断をしないと勝率の意味が変わるので、候補の点数に「ボスの残りHPに対するSSの価値」を入れる。
- 測る指標に「SSなしの勝率」を足し、SSが強すぎないか（なしでも勝てるが、使うと楽になる程度か）を見る。

## 3. フェーズ7：ギミック追加

### 3-1. 調べた仕様

| ギミック | 効果 | 対応アビリティ | 出典 |
| --- | --- | --- | --- |
| 地雷 | 触れるとダメージ。カウントが0になると爆発して周りにもダメージ。属性効果が乗る | マインスイーパー（MS）・飛行 | ゲームエイト |
| マインスイーパー | 地雷を回収して最大4個まとう。**最初にヒットしたときだけ**倍率ぶんのダメージ。MS 1.5 / M 2 / L 2.5 / EL 3倍。友情には乗らない | — | ゲームウィズ |
| 飛行 | 地雷を避けるだけ（回収しない）。ロックオン地雷は避けられない | — | ゲームウィズ |
| ワープ | 触れると吸い込まれ別のワープから出る。**ふつうは入った向きのまま出る**（ランダムなのは一部の敵が出すもの） | アンチワープ（超AWはワープ1か所につき攻撃力約5%アップ） | ピクシブ百科事典・ゲームウィズ |
| ブロック | 障害物。上下するからくり型もある | アンチブロック（通過できる） | ゲームエイト・ゲームウィズ |
| 魔法陣 | 踏むと「ひよこ」状態。攻撃力と友情が半減、SS使用不可（1/3とする資料もある） | アンチ魔法陣（魔法陣ブーストなら攻撃力と友情が1.5倍） | アルテマ・ゲームウィズ |
| 減速壁 | 触れると減速する壁 | アンチ減速壁（超なら触れると加速） | ゲームエイト・ゲームウィズ |
| ウィンド | 敵が味方を引き寄せる・引き離す | アンチウィンド（反風） | ゲームウィズ |
| 超アンチ重力バリア | 最初に触れたバリアで1度だけ加速 | — | ゲームエイト |
| 超アンチダメージウォール | 触れるとそのターン攻撃力約1.3倍（1度だけ） | — | ゲームウィズ |

### 3-2. 作るもの

| 追加 | 置き場所 | 実装 |
| --- | --- | --- |
| 地雷 | 物理：当たり判定なしの円（`fields` と同じ仕組み、`mine` イベント）。戦闘：ダメージ・回収 | 触れた瞬間に消えてチームHPを減らす。MS持ちは回収して `mines` を数え、次の直殴り1回に倍率。飛行は `blocked`。爆発カウントは後回し |
| ワープ | 物理 | ペアの円。入ったら相方の中心へ移動し、**向きと速さはそのまま**。出た直後は相方に入らない（`fieldsIn` と同じく出るまで無効）。ランダム出口は作らない（決定的にするため） |
| ブロック | 物理 | 止まっている矩形。**貫通タイプも跳ね返る**（敵と違う点）。アンチブロックは素通り |
| 魔法陣 | 物理：センサー。戦闘：状態 | 踏んだキャラに `chick: true`。次にそのキャラが撃ち終わるまで攻撃力・友情0.5倍、SS不可。アンチ魔法陣は無効 |
| 減速壁 | 物理 | 壁の一部。触れると速さに `slowWall.factor` を掛ける（ダメージウォールの物理版） |
| 超AGB・超ADW | 物理（加速）・戦闘（攻撃力） | 1ショット1回だけ。加速の倍率はサイトに確かな数値がないので自前で決める |
| ドラゴンの翼 | 物理 | 敵の形を「円の組み合わせ」にできるようにする（`shape: 'compound'`）。当たりは既存の `contact()` を部品ごとに回す |

ウィンドとシールド、敵のキラーは今回は作らない（ウィンドは物理の外力で予測軌道が複雑になるため、次の段階で検討）。

### 3-3. 自前で決める数値

サイトに具体値が載っていなかったもの。自動プレイで測って決める。

- 地雷1個のダメージ（案：チームHPの約3%）
- 減速壁の減速率（案：重力バリアと同じ55%）
- 超AGBの加速（案：1.5倍。「おそらく2.5倍」という記述はあるが確定情報ではない）

## 4. フェーズ8：ステージ内アイテムと新ステージ

### 4-1. 調べた仕様

| アイテム | 仕様 | 出典 |
| --- | --- | --- |
| ハート | 2ターンごとに 小→大→金 と育つ | ゲームエイト・ゲームウィズ |
| 回復量 | 小：取ったキャラの最大HPの半分、大：最大HPぶん、金：チームHPの75% | 検索結果（Yahoo!知恵袋ほか。要確認） |
| 出方 | 運が高いほど育った状態で出やすい | ゲームウィズ |
| 剣 | 取ったキャラの直殴り・友情・SSが1.5倍 | ゲームウィズ |

### 4-2. 作るもの

- ハート：ウェーブの開始と、敵を倒したときに**データで決めた位置**に出す（乱数を使わない）。`endTurn()` で2ターンごとに育てる。
- 剣：取ったキャラに `sword: true`。効果が続く長さはサイトで確かめられなかったので「取ったキャラの次の1ショットまで」とする。
- 新ステージ（3ウェーブ）：地雷・ワープ・ブロックを1つずつ使い、4体の得意が分かれるように置く。ステージ選択は2択のタイトル画面だけ作る。

## 5. 作らないもの（理由）

| 機能 | 理由 |
| --- | --- |
| アカウント・ガチャ・課金・運極などの育成 | サーバーが必要。1ファイルの方針と合わない。作るなら別プロジェクト（6章の法規制も参照） |
| マルチプレイ | 同上。物理は固定ステップで決定的なので、将来は「入力だけ送る」方式で載せられる |
| ゲージショット | 操作が増える割に遊びが変わらない（成功で攻撃力最大1.2倍） |
| ウィンド・シールド・ドクロ | フェーズ7が安定してから |
