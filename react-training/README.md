# React アプリ設計・実践研修（全4回）

前提知識ゼロから、**「どこに・どんなファイルを作ればいいか」を自分で決められるようになる**ための教材アプリです。
専門用語は使わず、レストランと部屋の片付けにたとえて、1回分ずつ進めます。

| 回 | テーマ | 内容 |
|---|---|---|
| 第1回 | アプリの全体像をつかむ | 3つの役割（🙋 ホールスタッフ＝コンポーネント / 🍳 キッチン＝カスタムフック / 🚚 仕入れ業者＝API）。仕分け練習つき |
| 第2回 | フォルダの分け方 | 種類別と機能別を、アプリの大きさを切りかえて比較。最小構成のフォルダツリー、受付窓口（index.ts）、shared の使い方 |
| 第3回 | 実際のコードを見てみる | 「お買い物メモ」の悪い例（1ファイル）と良い例（3ファイル）を動かして見比べる。分け方の手順、読みこみの向き |
| 第4回 | 実践演習 | 自分のアプリの機能を入力すると、フォルダ構成図とひな形コードができあがる |

各回に次の解説が付いています。

- **なぜこうするのか**（設計の理由と、分けすぎないための判断基準）
- **コードを見るときのポイント**（どのファイルから、どこを見るか）
- **レビューチェックリスト**（チェックは保存されます）
- **よくある失敗と見分け方**（見分け方・なぜ困るか・直し方）
- **理解度チェック**（選択クイズ＋ミニ課題。ヒントと模範解答つき）

前の回のクイズとミニ課題を終えると、次の回が開きます（ページ下の設定で、全部を自由に読めるようにもできます）。
進み具合は、ブラウザの localStorage に保存されます。

## 動かし方

```
npm ci
npm run dev      # 開発サーバー
npm test         # ロジックテスト（設計図ジェネレーター・コードの色分け）
npm run build    # 型チェック + ビルド（dist/ に出力）
```

## このアプリ自体の構成

教えている形（機能ごとのフォルダ＋3つの役割）で、このアプリも作っています。

```
src/
├─ App.tsx                    入口。回を切りかえて、機能を並べるだけ
├─ features/
│   ├─ lessons/               第1〜4回の本文と、回の切りかえ
│   ├─ quiz/                  クイズとミニ課題
│   ├─ checklist/             レビューチェックリスト
│   ├─ progress/              進み具合の保存（api / hooks / components）
│   ├─ shopping-list/         第3回の良い例（api / hooks / components の3ファイル）
│   ├─ shopping-list-bad/     第3回の悪い例（1ファイル）
│   └─ blueprint/             第4回の設計図づくり（api / logic / hooks / components）
└─ shared/
    ├─ components/            コード表示・囲み・見出しなど
    └─ lib/                   保存の道具、コードの色分け
```

第3回で表示しているコードは、`features/shopping-list*/` の実際のファイルを `?raw` で読みこんだものです。
説明と動いているコードがずれないように、コードを直すと表示も変わります。

## 内容を足す・直すとき

- 本文・クイズ・チェックリストは `src/features/lessons/components/Lesson1.tsx`〜`Lesson4.tsx` にあります。
- クイズやチェックリストの `id` を変えると、保存済みの答え・チェックは外れます。
- ひな形コードの中身は `src/features/blueprint/logic/generateBlueprint.ts`（テストは同じフォルダの `.test.ts`）。
