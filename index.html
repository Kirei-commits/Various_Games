Various Games

ブラウザだけで遊べるゲームと、学習アプリのコレクションです。
サーバーもインストールも要りません。リンクを開けばそのまま動きます。

GOD ARENA — 神器大戦

神から授かった武器で撃ち合う、属性つきの多人数バトル。 攻撃は同じ属性の防具でしか止まりません。 反射で撃ち返し、毒や封じで搦め手、瀕死には神の加護。

1〜5人の相手AI 3段階ゴッドフィールド風

NEURO GOMOKU — 五目並べ

ネオンが走るサイバーパンク五目並べ。AI対戦・2人プレイ・詰め五目。 長連・三三・四四の禁じ手ルールにも対応しています。

15×15禁じ手あり詰め五目

RIKAIDO RALLY — 理解度アップ・テストラリー

記述式で5問。正解するまでヒントで伴走します。 評価は A〜E で、ヒントを使うほど下がる仕組み。 採点基準・単元の選び方・レベルの上げ下げまで、その場で開示します。

Java の落とし穴桑田佳祐とサザン記述式・A〜E評価
どちらもビルド不要・実行時の依存ゼロ。スマホのタッチ操作にも対応しています。
