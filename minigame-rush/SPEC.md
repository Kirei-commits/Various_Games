最初の質問（36問）への回答をまとめたもの。1本目のミニゲームは **武器拾いレギオン**。

## 全体

| 項目 | 決定 |

## 武器拾いレギオンの基本ルール

- 画面の下半分は **横5×縦6の盤面**。どのマスにも武器が置いてある。
- 盤面には英雄が何体もいる。**好きな1体を指でドラッグ**して動かす。
- 英雄が武器のマスに触れると、**得意な武器だけ**を拾う（弾として持てる数には上限がある）。拾った武器は自動で投げる。
  - 動かしていない英雄も、足元に流れてきた得意武器を拾って投げる。
- 武器は**英雄のいる列の真上**へ飛ぶ。左に寄れば檻、右に寄れば敵やゲートに当たるので、どこに立つかが作戦になる。
- 拾って空いたマスには奥から武器が詰めてくる。さらに数秒ごとに盤面全体が手前へ1段流れ、奥から新しい列が来る。
- 同じ種類で同じ段階の英雄に重ねてドロップすると **合体して1段階進化**する（最大★4）。ほかの英雄の上に落とすと場所を入れ替える。
- 敵が盤面の手前（拠点）まで来ると拠点HPが減る。0 で負け。英雄が攻撃されることはない。
- **敵は途切れずに行進してくる**（ステージの最初はまばらで、だんだん詰まる。ときどき大群が押し寄せる）。
- 武器には射程があり、遠くの群れには届かない。奥の段に立つほど遠くまで届く。

## 武器と英雄（9種類 × 4段階）

| 武器 | 特徴 | 英雄 |
|---|---|---|
| 鎌 | 回転しながら飛び、敵を貫通する | 死神 |
| 剣 | 一撃が重い | 騎士 |
| 杖 | 近くの敵を追いかける魔法弾 | 魔法使い |
| パチンコ | 当たると小さく爆発する（範囲攻撃） | いたずら小僧 |
| 弓 | 3方向に広がって飛ぶ | エルフ |
| 槍 | 弾が速く、射程いっぱいまで貫通する | 槍兵 |
| 斧 | 当たり判定が大きく、2体まで貫通する | 戦士 |
| 爆弾 | 遅いが大きく爆発する | ボマー |
| 手裏剣 | 連射が速く、当たると次の敵へ跳ねる | 忍者 |

- 段階は ★1〜★4。上の段階ほど威力と連射が上がり、見た目も変わる（マント→王冠→オーラ）。
- 盤面には持っていない英雄の武器も混ざる。その英雄を手に入れると、混ざっていた武器も使えるようになる。

## 檻の英雄

- 檻の中に鎖で縛られた英雄がいて、頭の上の数字（HP）を武器で削ると解放できる。放っておいても消えずに待っている。
- 解放したら2択から選ぶ。**「仲間にする」**（その英雄が盤面に加わる）か、**「進化させる」**（自分の英雄を1体選んで★を1つ上げる）。
- 1つ解放すると、次の檻が現れる。

## マップ（ステージごとに形が変わる）

1. 左の檻＋右の通路（広告と同じ）　2. 右の檻＋左の通路　3. 二本道＋中央の檻
4. 大通り＋奥の檻　5. 両側の檻＋中央の通路

## 敵（10種類＋ボス3種類）

ゴブリン / 韋駄天ゴブリン（速い） / 重装オーク（HPが多い） / 盾持ち（ダメージを毎回一定量減らす） /
ガイコツ（一度だけ復活する） / スライム（倒すと2匹に分裂する） / コウモリ（左右に揺れながら来る） /
ゴースト（ときどき透けて攻撃がすり抜ける） / 呪術師（まわりの敵を回復する） / 爆弾ゴブリン（拠点へのダメージが大きい）

ボス: ゴブリンキング（手下を呼ぶ） / 巨大スライム（分裂する） / 闇の騎士（硬く、ときどき突進する）

## ゲート（数字付きの箱。壊すと効果が出て、そのステージ中ずっと続く）

**よいゲート**: 英雄の数 +N / 攻撃速度 ×N / 攻撃力 ×N / 貫通 +1 / 弾数 +1 / 弾速アップ / 弾が大きくなる /
会心率アップ / 特定の武器の威力 ×2 / 弾を持てる数 +2 / 拠点回復 / バリア（次の数体分のダメージを防ぐ） /
武器フィーバー（盤面が持っている英雄の武器だけになる） / 敵が遅くなる / 雷（画面中の敵全部にダメージ） /
ランダムな英雄1体が進化 / コイン +N

**わなのゲート（赤）**: 攻撃力ダウン / 攻撃速度ダウン / 敵が増える / 敵が速くなる / 英雄が1体減る
→ わなのゲートは壊さないように、撃つ列を外して避ける。

## 進め方

- **ステージモード**: ステージは自動で作り、全99ステージ。1ステージ3分くらい。最後のボスを倒せばクリア。
  拠点HPの残りで ★1〜★3 の評価がつく。
- **エンドレスモード**: 敵は無限に来て、檻とゲートも次々に出る。到達ウェーブと撃破数がスコアで、最高記録を保存する。
- **難易度**: かんたん / ふつう / むずかしい から選ぶ（進み具合は難易度ごとに別）。難しいほどもらえるコインが多い。
- **永続強化（コイン）**: 攻撃力 / 攻撃速度 / 拠点HP / 最初の英雄の数 / 弾を持てる数 / コイン獲得量
- **英雄図鑑**: 出会った英雄の種類と段階を記録する。
