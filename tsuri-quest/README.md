# つりクエスト — TSURI QUEST

7種類の魚を釣り上げてレベルを上げる、ブラウザだけで遊べる釣りゲーム。
**ビルド不要・実行時依存ゼロ**。`index.html` をブラウザで開けばそのまま動きます。

## 遊びかた

1. **キャスト** — 大きなボタンを押して仕掛けを投げる
2. **アタリを待つ** — ウキが沈むまで待つ（早く押すと「早合わせ」で逃げられる）
3. **合わせる** — 「合わせる！」に変わったら押す。レアな魚ほど猶予が短い
4. **巻く** — **押し続けている間だけ巻ける**。テンションが赤に入ると糸が切れる。
   離すと緩むので、上げて・緩めてを繰り返して取り込む

キーボードなら **スペース／Enter** でも同じ操作ができます（押しっぱなしで巻き取り）。

## 魚と得点

| 魚 | レア度 | サイズ | 基礎点 |
|---|---|---|---|
| アジ | ★☆☆☆☆ | 15〜30cm | 10 |
| サバ | ★☆☆☆☆ | 25〜45cm | 15 |
| スルメイカ | ★★☆☆☆ | 20〜40cm | 25 |
| マダイ | ★★☆☆☆ | 30〜70cm | 40 |
| ブリ | ★★★☆☆ | 60〜110cm | 80 |
| クエ | ★★★★☆ | 80〜150cm | 160 |
| リュウグウノツカイ | ★★★★★ | 200〜500cm | 400 |

```
ポイント = 基礎点 × サイズ倍率(0.6〜2.0) × コンボ倍率(1.0〜2.0) × 天候倍率
```

同じ魚でも、最小サイズと最大サイズでは **3倍以上** の差がつきます。

## 成長のしくみ

- **レベル（1〜30）** — 累計ポイントで上がる。買い物では減りません。
  レベルが上がるほど**レアな魚の出現重みが増え、コモンの重みが減ります**
  （コモンが消えるのではなく、比率が滑らかに移ります）。
  Lv1 でも伝説は 0.1% ほど出るので、初回から夢があります。
- **所持ポイント** — 道具の購入に使う通貨。獲得時にレベル用の累計と同額が増えます。
- **エサ／ルアー**（5種） — アタリの速さ・レア寄せ・大物寄せ。キャストごとに1つ消費。
- **竿**（5段階） — 取り込みが速くなり、合わせの猶予が伸びる。
- **糸**（5段階） — 切れるテンションの限界が上がり、強く巻ける。
- **時間帯**（朝マヅメ／日中／夕マヅメ／夜）と**天候**（晴れ・くもり・雨・嵐）が
  キャストごとに移り変わり、出現する魚が変わります。
  リュウグウノツカイは**嵐の夜**がねらい目。
- **コンボ** — 連続で釣り上げるとポイント倍率が最大2倍まで上がる。バラすと0に戻ります。
- **図鑑・ベスト記録・実績（11種）と称号** — すべて localStorage に保存されます。

まじめに釣り続けると **240〜320キャスト** ほどで Lv30 に到達します
（`tests/logic/balance.test.mjs` がこの範囲をCIで見張っています）。

## 開発

```bash
npm ci               # 開発用の依存（Playwright のみ）を入れる
npm start            # http://127.0.0.1:8081/ で配信
npm run lint         # 構文チェック・参照整合性・読み込み順・状態キーの定義漏れ
npm run test:logic   # 抽選・得点・状態機械・永続化・バランス（Node標準のテストランナー）
npm run test:e2e     # ブラウザテスト（デスクトップ + スマホのタッチ）
npm test             # 上記すべて
```

デバッグ用のURLパラメータ:

| パラメータ | 効果 |
|---|---|
| `?reset=1` | セーブデータを消して開く |
| `?seed=123` | 乱数を固定する（抽選が決定的になる） |
| `?debug=1` | `FQ.app.debug.*`（待ち時間の短縮・ポイント付与など）を有効にする |

設計上の制約と、過去にやらかした手戻りの記録は [CLAUDE.md](./CLAUDE.md) にあります。
