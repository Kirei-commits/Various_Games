# つりクエスト — TSURI QUEST

30種類の魚を釣り上げてレベルを上げる、ブラウザだけで遊べる釣りゲーム。
**ビルド不要・実行時依存ゼロ**。`index.html` をブラウザで開けばそのまま動きます。

## はじめかた

最初に**ログイン画面**が出ます。

- **新規作成** — 名前とパスワードを決めると、その名前でセーブデータが作られます。
  作成直後に「**名前 / パスワード / バックアップコード**」を控える画面が出ます。
  **パスワードを忘れると元に戻せません**（この端末の中だけで完結しているため、
  再発行のしくみがありません）。かならず控えてください。
- **続きから** — 作成時の名前とパスワードでログインします。
- **バックアップコードから復元** — 別の端末やブラウザへデータを持っていくときに使います。

> セーブデータはブラウザの localStorage に保存されます。したがって
> **別の端末・別のブラウザ・シークレットウィンドウには引き継がれません**。
> 移すときはバックアップコード（記録タブからいつでもコピーできます）を使ってください。
> パスワードはスロットを分けるための鍵で、暗号による保護ではありません。

## 遊びかた

1. **キャスト** — 大きなボタンを押して仕掛けを投げる
2. **アタリを待つ** — ウキが沈むまで待つ（早く押すと「早合わせ」で逃げられる）
3. **合わせる** — 「合わせる！」に変わったら押す。レアな魚ほど猶予が短い
4. **巻く** — **押し続けている間だけ巻ける**。テンションが赤に入ると糸が切れる。
   離すと緩むので、上げて・緩めてを繰り返して取り込む

キーボードなら **スペース／Enter** でも同じ操作ができます（押しっぱなしで巻き取り）。

## 魚 30種

| レア度 | 種類数 | 例 | 基礎点 |
|---|---|---|---|
| ★☆☆☆☆ | 8 | マイワシ・アジ・ハゼ・サバ・カワハギ・メバル・キス・ボラ | 8〜27 |
| ★★☆☆☆ | 8 | スルメイカ・カサゴ・アオリイカ・マダイ・スズキ・カンパチ・タチウオ・ヒラメ | 32〜70 |
| ★★★☆☆ | 6 | ブリ・サワラ・イシダイ・ヒラマサ・マハタ・アカムツ | 80〜160 |
| ★★★★☆ | 5 | クエ・キハダマグロ・クロカジキ・マンボウ・オオカミウオ | 190〜410 |
| ★★★★★ | 3 | リュウグウノツカイ・ラブカ・ダイオウイカ | 500〜900 |

```
ポイント = 基礎点 × サイズ倍率(0.6〜2.0) × コンボ倍率(1.0〜2.0) × 天候・ブースト倍率
```

同じ魚でも、最小サイズと最大サイズでは **3倍以上** の差がつきます。

## 2つのレベル

役割を分けています。片方に両方の役割を持たせると、上げる意味が一本しか残らないためです。

| | 何で上がる | 何が良くなる |
|---|---|---|
| **釣果レベル**（1〜30） | 獲得ポイントの累計 | **何が釣れるか**。レアの出現重みが Lv1 の値から Lv30 の値へ滑らかに移る |
| **釣り人レベル**（1〜20） | 釣る・バラす（＝行動） | **釣りの快適さ**。合わせの猶予・アタリの速さ・取り込みの速さ・糸の粘り・コンボ保護 |

釣果レベルが上がってもコモンが消えるわけではなく、比率が移るだけです。
Lv1 でも伝説は 0.13% ほど出るので、初回から夢があります。

## ショップ

| 種類 | 内容 |
|---|---|
| **エサ・ルアー**（5種） | アタリの速さ・レア寄せ・大物寄せ。キャストごとに1つ消費 |
| **ブーストアイテム**（5種） | ポイント2倍／レアラッシュ／大物／高速アタリ／糸切れ防止。決まったキャスト数だけ持続し、**重ねがけできる** |
| **パーツ・装飾品**（18種） | リール6種（巻き速度と緩めやすさ）／ウキ6種（見た目＋合わせの猶予）／ロッドカラー6種（見た目だけ）。買ったものは持ち替え可 |
| **竿**（5段階） | 取り込みが速くなり、合わせの猶予が伸びる |
| **糸**（5段階） | 切れるテンションの限界が上がる |
| **コード入力** | `aaa` を入れると管理者モード（**全商品が0円**）。いつでも解除できます |

道具の効果は担当を分けてあります（竿＝速度と猶予、糸＝限界、エサ＝待ち時間とレア寄せ、
リール＝巻きと緩め、ウキ＝猶予）。ひとつで全部良くなると、選ぶ意味がなくなるためです。

## そのほか

- **ログインボーナス** — 1日1回。7日で一巡し、7日目がいちばん大きい。1日でも空くと1日目に戻ります。
- **時間帯**（朝マヅメ／日中／夕マヅメ／夜）と**天候**（晴れ・くもり・雨・嵐）が
  キャストごとに移り変わり、出現する魚が変わります。深海の魚は**嵐の夜**がねらい目。
- **コンボ** — 連続で釣り上げるとポイント倍率が最大2倍まで上がる。バラすと切れますが、
  釣り人レベルが高いと一定確率で半分だけ残ります。
- **図鑑・ベスト記録・実績17種と称号**。

まじめに釣り続けると **250〜400キャスト** ほどで釣果レベル30に到達します
（`tests/logic/balance.test.mjs` がこの範囲をCIで見張っています）。

## 開発

```bash
npm ci               # 開発用の依存（Playwright のみ）を入れる
npm start            # http://127.0.0.1:8081/ で配信
npm run lint         # 構文チェック・参照整合性・読み込み順・状態キーの定義漏れ
npm run test:logic   # 抽選・得点・状態機械・アカウント・永続化・バランス
npm run test:e2e     # ブラウザテスト（デスクトップ + スマホのタッチ）
npm test             # 上記すべて
```

デバッグ用のURLパラメータ:

| パラメータ | 効果 |
|---|---|
| `?reset=1` | localStorage を消して開く（消したあとURLからは自動で外れます） |
| `?seed=123` | 乱数を固定する（抽選が決定的になる） |
| `?debug=1` | `FQ.app.debug.*`（待ち時間の短縮・ポイント付与など）を有効にする |

設計上の制約と、過去にやらかした手戻りの記録は [CLAUDE.md](./CLAUDE.md) にあります。
