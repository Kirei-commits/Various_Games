## 3. 音声（TTS）の仕組みづくり

- 目的：**アメリカ英語のネイティブの自然な発音・音の変化（リンキングなど）** を聞けるお手本。
- アプリ側：録音（`audio/clips/*.opus`）があれば再生し、無ければ端末の声に戻す（`src/recorded.js`）。
  - 設定「ネイティブ音声（録音）を使う」、速さは「話す速さ」で再生速度を変える（音の高さは変わらない）。
- 声の聞き比べ（10声）→ **見出し = Erinome、A = Achird、B = Callirrhoe** に決定。
- 分かったこと：
  - 話し方の指示を読む文に混ぜると、指示まで読んだり文を何度も繰り返したりする
    → 指示は `speechMetadata.style` で送る（これなら効く）。`systemInstruction` はこのモデルでは使えない。

## 4. 生成がとても遅かった・止まった理由

- 1つずつ順番に送っていた → 並列にして約4倍速く。
- **本当の原因は API の上限**：各 TTS モデルは **1日100回**（1分10回・1分1万トークン）。
- 対策の検討：
  - 安いモデルでも可、上から順にモデルを使う（2.5 Pro TTS は料金2倍なのでとばす）。
  - 複数の文を1回で読ませて無音で切る方式を作った（切れないときは推測せず小さく分けて作り直す）。
  - 途中で見つけた不具合（1文ずつ方式が次のモデルまで続く、2声だと間が短くて切れない など）を直した。
  - この方式で1日目に 2,800文。
- 費用：AI Studio の表示で ¥402（ほとんど画像の分）。見積もりが低すぎたことを反省。

## 5. Batch API に切り替え

- ユーザーの質問「Batch API でも送る量は変わらない？」→ **Batch は1日100回の上限とは別枠・半額**。
- 方針：**Batch で 3.8 Flash TTS・1文ずつ**（まとめる必要が無くなり、安く・質もそろう）。
- 試し20文 → 2文に「言い直し（くり返し）」があった
  → style に「1回だけ・言い直さない」を足し、取り込むときに安いモデルで文字起こしして語数を確かめる。
- ユーザーの指示：**2回目までは同じ指示で出し直し、3回目以降は原因を調べて直して送る自己完結のサイクル**
  → 失敗の種類（くり返し／言い落とし）に合わせた指示を足す。表記の違い（I'm/I am、5/five など）は失敗にしない。最大5回。
- 残り約1万文を52件のバッチで一度に出した → 1件数分で届いた。
- **ほかのモデルで作った約2,900文も 3.8 Flash TTS に置き換える**（ユーザーの指示）。
- 途中の問題と対処：
  - 取り込み中の録音がリポジトリに出て未コミットになる → 確認中は git の外に置き、通ったものだけ入れて1件ごとにコミット。
  - 同時に動かした処理がジョブの一覧を上書きし、11件が消えた → Batch の一覧 API から取り戻し、書く前に読み直してまとめるように直した。
  - `tts.py` の構文エラー（合いの手の部分で1行消えていた）を見つけて直した。

## 8. 確認を Claude でできない？ → 無料の Whisper を使いたい

- Claude は音声を聞けないので、文字起こしの仕組みが別に必要。Gemini を使ったのは、すぐ使えたから（無料の方法の検討が足りなかった）。
- **無料の方法**：このコンテナで Whisper（オープンソースの音声認識）を動かす。
  - モデルのダウンロード先（`huggingface.co`、`cdn-lfs.huggingface.co`）がネットワーク設定で止められている。
- ユーザーが web（claude.ai/code）で「クラウド環境を編集」を開けた（スマホアプリからは開けなかった）。
  - **ネットワークアクセス →「カスタム」** で上の2つを追加する（Trusted の既定の分が消える形なら、
    `generativelanguage.googleapis.com`・`pypi.org`・`files.pythonhosted.org`・`registry.npmjs.org`・`github.com` も追加）。
  - **変更は新しいセッションから効く**。新しいセッションでは置き換え待ちの2,918本は引き継がれない（出し直し 約¥60）。
  - 出し直しと合いの手には Gemini を使うので、残高の追加は少し必要（Whisper で無料になるのは確認だけ）。

## 9. 新しいセッションでの頼み方

> `eikaiwa-swipe/HANDOFF.md` と `eikaiwa-swipe/SESSION_LOG_2026-09-28.md` を読んで、録音の確認の続きをして。
> 確認は無料の Whisper（faster-whisper）でやって、確認に通らなかった文と置き換えは Batch で出し直して、最後に合いの手の声を作って。

やること（順番）：
1. `tools/media/setup.sh`、faster-whisper を入れてモデルを落とせるか確かめる。
2. 未確認（manifest の `unverified`）を Whisper で確認する（`tts.py` の `check_clip` を Whisper で動くようにする）。
3. `python3 tools/media/tts.py submit all --replace-models` → `collect` をくり返す（残高の追加が必要）。
4. `python3 tools/media/tts.py cheers`（作る前に回数と金額を確認）。
5. lint・テスト・アプリで鳴ることを確かめてコミット。HANDOFF.md を更新。
