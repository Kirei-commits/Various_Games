# SwipeTalk（スワイプ式 英会話フレーズ学習）

Tinder 風のスワイプで英会話フレーズを仕分けて覚え、テストとシャドーイングで「話せる」まで鍛えるモバイルファーストの学習アプリです。
**全110章 × 50問 = 5500問（フレーズ2500・単語3000）**。`index.html` をブラウザで開けばそのまま動きます（サーバー不要）。

| 部 | 章 | 内容 |
|---|---|---|
| 基本編 | 1〜20 | あいさつ、あいづち、感情、日常生活、句動詞、イディオム、スラングなど |
| アメリカ生活編 | 21〜40 | 注文、空港・入国審査とトラブル、ホテル、アパート契約と修理、病院・薬局・保険、銀行、スマホ契約、車、緊急時、役所、職場、学校・子育て、近所づきあい、雑談、ていねいなお願い、苦情・交渉 |
| もっと話せる編 | 41〜50 | 励ます・ほめる、考え中・あいまいな返事、聞き返す・話をつなぐ、デート・恋愛、ゲーム・動画・推し活、お祝い・パーティー、運動・健康習慣、家族・子ども・ペット、会議・プレゼン、ことわざ |
| 単語編・基礎 | 51〜70 | 基本動詞、基本の形容詞・副詞、時間・数・家族・体・家・料理・食べ物・服・色・町・乗り物・自然・動物 |
| 単語編・生活 | 71〜90 | 学校、職業、オフィス、お金、気持ち・性格、趣味、旅行、医療、スマホ・ネット、日常動作・話す・考える動詞、評価の形容詞、副詞、前置詞、生活用品、家事、恋愛・冠婚葬祭、事件、ニュース |
| 単語編・応用 | 91〜110 | 経済、科学・環境、芸術・メディア、法律・役所、抽象名詞、上級の動詞・形容詞・副詞、数学、地理、宗教・歴史・行事、スラング、アメリカ英語、身の回りの名詞、変化の動詞、食事と味、動きを表す語 |

単語は1語ごとに意味と、会話でそのまま使える例文（訳つき）が付いています。章を選ぶ画面には各章・各部の問題数が出ます。

## 画面

| 画面 | 内容 |
|---|---|
| 学習 | 章を選んでカードを仕分け。右スワイプ（⭕️）で覚えた＝出題から外す、左スワイプ（❌）で最後尾へ。タップで日本語訳と A/B の会話例（単語は例文）と、リンキング（音のつながり）の説明。PC では ← / → / Space でも操作可能。 |
| テスト | 出題の向き（**英語 → 意味** / **日本語 → 英語**）、出題範囲（各章・全章・フレーズ全部・単語全部・苦手な問題）、問題数（10/20/50）、出し方（英語を表示／音声だけ）、答え方（入力／音声／4択）を選んで受験。間違えた問題は「未習得」に戻して学習カードの最後に追加し、「苦手な問題」に集めます。 |
| シャドー | 見出しと会話例を1行ずつ「お手本 → あなたの番」で自動再生。英文を隠す、訳の表示、間の長さ、前後のフレーズ移動、発音チェック（聞き取れた単語を色分けし、違った語は「何と聞こえたか」と原因の推定〔th・R/L・V/B・語尾の子音など〕と直し方を表示。「振り返り」で過去の結果とよくあるつまずきを見直せる）。 |
| 一覧 | 5500件を英語・日本語で検索、章・フレーズ／単語・習得状況・⭐お気に入りで絞り込み。綴りが少し違っても「もしかして」で近いフレーズを出す。各行から音声再生、会話例の展開、覚えた／未習得の切り替え。 |
| ガチャ | 単語（3000語＋シークレット）を集める単語ガチャ・図鑑（単語と実績）・マイ称号・コード・メダルショップ。下の「単語ガチャ」を参照。 |
| 日記 | 今日のことを自由に書く（英語でも日本語でも）。気分・今日のお題つき。これまでの日記を日付ごとに見返せる。 |
| 進捗 | 全体の習得率、連続学習日数、今日の学習数、累計スワイプ、テスト解答数、シャドーイング回数、苦手な問題数、部・章ごとの進み具合と「意味」「英語」それぞれのテスト最高点（章を押すと「学習する」か「一覧で単語を見る」を選べる）。ログインボーナス（5倍ブーストの所持数・残り時間）、今日の目標（20枚）の達成ボーナス。 |

- リンキング（音のつながり）: 英文の、つながって発音される単語の間に ‿ を重ねて表示し（文字列は変えないので読み上げ・コピーに影響しない）、
  want to → wanna、did you → didja、get it → ゲリッ（やわらかい t）、twenty → トゥエニー（消える t）、tell him → テリム（消える h）などを
  理由つきで説明します（`src/linking.js`、綴りからの推定）。設定でオフにできます。
- 毎日最初に開くとログインボーナス（ガチャポイント 300pt・**5倍ブースト**1つ・SR ガチャチケット3枚。累計3日ごとに SSR ガチャチケット、
  連続7日ごとにレアチケット）を受け取れます。
  5倍ブーストを使うと1時間、学習・テスト・バトルでもらえるガチャポイントが5倍（使用中にもう1つ使うと延長）。
- 着せかえ（カードと画面の色）は設定（⚙）からいつでも無料で選べます（以前のコインは廃止）。
- 音声を流す画面（学習・シャドーイング・一覧・テスト）には **話す速さのバー**（🐢〜🐇）があり、その場で速さを変えられます（設定の「話す速さ」と同じ）。
- 読み上げはすべてネイティブの録音（アメリカ英語）です。録音の無い文（日記など）だけ、端末の英語の声を自動で選んで読みます。
  （以前あった声の選択・「会話ごとにいろいろな人の声」「いろいろな国の英語の声」「抑揚」「A と B で声を変える」・録音のオン/オフの設定は、録音ができたのでなくしました）
- 合いの手の声は、オンなら起動時に全部読み込んでおき、ボタンを押した瞬間に鳴らします（Web Audio。使えない端末は読み込み済みのデータを <audio> で）。
- ⭐ お気に入り: 学習カード・一覧・バトルの結果・ガチャの単語カード・冒険の装備選びで単語に ⭐ を付けられます。
  一覧・図鑑・装備選びの「お気に入りだけ」で絞り込め（図鑑は「お気に入りを先に」「強化の高い順」「ABC 順」の並べ替えも）、テスト・バトルの出題範囲にも使えます。
- 効果音は木琴のようなやわらかい音（設定でオフ・音量調整可）。BGM は、学習中はゆったりしたローファイ風の曲（読み上げ中は小さくなり、
  シャドーイング中は止まる）、バトル中は冒険の曲。どちらも設定でオフ・音量調整できます。
- **ドーパミンモード**（設定）: 正解・「覚えた」のたびに紙吹雪と「NICE! → GREAT! → PERFECT!!!」、連続正解ほど音が上がり、10連続で画面のふちが虹色に光る演出。
  連続の数は画面の上に小さく出し、絵文字の雨は5連続ごとの節目だけにしています（問題が見えにくくならないように）。
  テストは正解すると「次へ」を待たずに次の問題へ進みます（スマホは軽く振動）。
- 新しい版が公開されると、画面上部に「更新する」バナーが出ます。ホーム画面に追加する URL は普通の URL のままで大丈夫です。
- 進捗のリセットは設定の奥にあり、3回確認してから実行します。
- **アカウントのデータを消す**（設定の一番下）: 学習記録・ガチャ・バトル・冒険・日記をすべて消して最初から始めます
  （ログイン中はクラウドの保存も空にしてログアウト）。3回タップして確認してから実行します。
- 出題範囲（テスト・バトル・冒険の問題）は章のほか、**「基本編」「アメリカ編」などの編まるごと（1000問など）**からも選べます。

### バトル（RPGモード）

テスト画面の「テスト／バトル／冒険」で切り替えます。迫ってくる敵（単語）に答えて倒します。

- 出題範囲はタップで開いて選びます（「まとめて」「単語の難易度（5段階）」「部」のグループをタップすると中身が出る）。
  **難易度5段階**は、単語3000語を難しさ（章の順と語の長さ）で600語ずつに分けたもの（★1 やさしい〜★5 超むずかしい）。
- **ステージ**: 章（または難易度・お気に入り・苦手）がステージ。敵の数を **10・50・100体** から選び、全部倒すとボス（HP3。攻撃のたびに別の単語を出してくる）。倒せばクリア
  （画面いっぱいの光と「STAGE CLEAR!」の演出のあと結果へ）。章の問題より多い数を選ぶと、同じ単語がもう一周出ます。
  ノーダメージで★3、HP 半分以上で★2。
- 敵が出ると、表示している英単語を読み上げます（英語→意味のとき。日本語→英語では答えになるので読みません）。
- **エンドレス**: 10体倒すごとにレベルが上がり、敵が少しずつ速く（1レベル +7%、最大2倍）・多く（3レベルごとに+1体、最大4体）なります。
  HP がなくなるまで続け、最高得点を記録します。
- 出題の向き（英語→意味／日本語→英語）と答え方（4択／入力／音声）を開始前に選べます。入力・音声のときは敵がゆっくり近づきます。
  敵が上から届くまで、4択は15秒・入力は26秒・音声は22秒（エンドレスはレベルが上がると少しずつ速くなる）。
  次の敵は4択で2.4秒ごとに出てきて、倒すとすぐ（場が空なら0.25秒、ほかの敵がいても0.9秒以内に）次が出ます。
- 一番近い敵の単語に答えると攻撃（複数いるときは、**敵をタップするとその敵を狙えます**）。正解が続くとコンボで得点アップ。間違えると敵が一気に近づき、正解が表示されます。
  敵が届くと HP が減ります（HP5、ボスは2ダメージ）。ほかのタブを見ているあいだは止まります。
- 間違えた・逃した単語はテストと同じく「苦手」に入り、学習カードの最後に戻ります。
- 出てくる順番は「ランダム」か「難易度順」（やさしい章・短い単語から、だんだん難しく。近い難しさの中ではランダム）。
- 報酬（3体以上倒したとき）: ガチャポイント 300〜900pt（遊んだ時間ぶん＋正解率・クリア・最高得点更新で上乗せ）と
  レアチケット 1〜8枚（ステージは ★1=2・★2=4・★3=6 枚、初めての★3は +2。エンドレスは 1＋(レベル−1)/2 枚）。1日の上限なし。
  エンドレスはさらに**到達レベルのボーナス** 150 ×（1＋2＋…＋(レベル−1)）pt（Lv5 で 1,500、Lv10 で 6,750、Lv15 で 15,750）。
- **道具**（ガチャのメダルショップで交換）: 時止めの砂時計（敵が5秒止まる）、必殺技の巻物（わからない単語の敵を一撃で倒す。その単語は苦手に入る）。
- 結果画面は「次のステージへ・もう一度・設定に戻る」が一番上。撃破した単語をタップで答えを確かめながら復習でき、⭐ でお気に入りにできます。
- 絵と演出: 敵10種（スライム・コウモリ・おばけ・キノコ・ゴブリン・ドクロ・目玉・火の精・ゴーレム・インプ）とボスのドラゴン、
  主人公の魔法使い、夜の戦場（`src/battle-art.jsx`。絵は `src/assets/battle/`、Gemini で生成）。単語ごとに同じ敵が出ます。
  攻撃すると魔法の弾が飛んで斬撃・爆発・得点が出て、ダメージを受けると画面が揺れて赤く光ります。
- BGM: バトル中は冒険のループ曲（ボス戦は曲調が速くなる）。ほかのタブ・アプリに切り替えると止まります。
- 進行は `src/battle.js`（時間と乱数を引数で受け取る純粋なエンジン。テストあり）。

### 冒険（ドラクエ風モード）

テスト画面の「冒険」。ガチャで集めた単語を**装備**にして、塔を1階ずつ登るターン制の RPG です（敵の絵はバトルと同じ）。

- **装備**: 7か所（武器＝攻撃力・盾＝守備力とぼうぎょ・頭＝守備力と MP・体＝HP と守備力・腕＝攻撃力と会心・足＝みかわしと守備力・アクセ＝HP と MP）。
  どの単語もどこにでも付けられます。「おまかせ装備」で強い順に自動で付けます。
- **強さはレア度で分かれる**: 土台 N 6・R 14・SR 28・SSR 50、Lv（ダブり）1つごとに +2／+4／+7／+12。
  さらに「かっこよさ」（長い単語・熟語・x/z/q/j を含む単語ほど少し強い。倍率はレア度ごと）を足します。
- **単語ごとの効果**: 品詞で種類が決まり、数値はレア度で決まります（SSR は効果が2つ）。
  **SSR には属性ごとの特製の呪文**が付きます: フレイムバースト（炎の大ダメージ）・ブリザード（敵を1ターン止める）・ライトニング（守備を無視）・
  ホーリーライト（攻撃と HP 回復）・ダークドレイン（ダメージの半分を吸収）・メテオストライク（無属性の超こうげき）。
  名詞＝守備力・HP アップ・自動回復、動詞＝攻撃力アップ・会心・HP 吸収、形容詞＝みかわし・属性強化・自動回復、その他＝MP・経験値アップ・会心。
- **属性**: 炎・氷・雷・光・闇。fire・snow・storm・light・night など意味から決まり、ほかは単語ごとに決まります（レアほど属性付き）。
  武器の属性で攻撃し（炎→氷→雷→炎、光⇔闇 で1.5倍）、盾と同じ属性の攻撃は半分に。4か所の属性がそろうと攻撃力 +15%（7か所で +30%）。
- **呪文の MP**: 消費は「呪文ごとの基本＋最大 MP の2割」（極の呪文は1.2倍）。満タンから3〜4回まで。**毎ターン最大 MP の4%が戻る**ので、
  ぼうぎょ（最大 MP の1割）や階の移動（2割）と合わせて、ボスまでためておくこともできます。
- **敵の強さ**: 深い階ほど一気に強くなります（HP・攻撃・守備とも階の2乗で伸びる）。目安は、N/R の装備で10階前後、
  SR そろいで20〜25階、SSR 入りの強い装備で40階台。
- **戦闘**: 「たたかう」と SSR 装備の呪文は、英単語の意味の4択に正解すると攻撃、間違えるとミス（ふつうの「じゅもん」はない）。
  **「ぼうぎょ」も4択に答え**、間違えると身をまもれません（大こうげきもそのまま受ける）。
  **熟語**: 8階から「wake up」「take a shower」などの熟語（フレーズの章の2〜4語の句、約750個）も混ざります（最初は2割、1階ごとに +2%、最大5割）。
  冒険の画面の「熟語も出す」をオフにすると単語だけになります。
  単語は問題が出たときに読み上げます。敵の名前の下に、今の攻撃の相性（×1.5 ばつぐん など）、コマンドの上に相性表が出ます。
  「ぼうぎょ」でダメージ半分と MP 回復（最大 MP の1割）、「やくそう」で HP 回復（1回の冒険で3つ、ボスを倒すと +1）。連続正解でダメージアップ、会心は1.8倍。
- **敵の大こうげき**: 敵はときどき「ちからをためる」（ボスは3ターンごと）。次のターンの大こうげき（2.6倍・ボスのブレスは3倍、かわせない）は、
  ぼうぎょで受けとめると 1/4 以下に減らし、はんげきします（盾が強いほど減らす）。画面に「大こうげきが来る！」と出て、敵が赤く光ります。
- 演出: 斬撃・爆発・粒・ダメージの数字、呪文の弾と属性のエフェクト（炎の渦・氷の結晶・雷・光の柱・闇の渦・隕石）、敵の突進と画面のゆれ、
  ためのオーラ、盾のバリア・回復の光、倒した敵が光って消える。効果音つき。
- 絵: 塔の中の背景・主人公の剣士・装備7か所と属性・呪文のアイコン・攻撃のエフェクト（`src/quest-art.jsx`、絵は `src/assets/quest/`）。
  Gemini で 3×3 のまとめ絵を描かせて切り分けたもの（エフェクトは黒い背景で描かせ、明るさを透明度にしている）。
- 5階ごとにボス（ドラゴン）。倒した階は記録され、次からはボスの次の階から始められます。負けても経験値はなくなりません。
- **報酬**はバトル（エンドレス）と同じ水準: 300〜900pt（時間ぶん × 正解率・ボス・最高記録）＋ 到達ボーナス（3階倒すごとに1レベル。
  150 ×（1＋…＋(レベル−1)）pt）＋ レアチケット 1〜8枚。経験値で Lv が上がる。間違えた単語は「苦手」に入ります。
- **宝箱**: 5階ごとのボスを倒すと1つ。ガチャのポイント（90 × 5階ごとの段）と、冒険限定の単語（45%）・レアチケット・メダル・SR チケット（15階から）のどれか。
  **冒険限定の単語**（36語。map・ship・storm・brave・legend・king など）はガチャ・交換所には出ません。深い階ほどレア
  （10階まで N/R、20階まで SR も、30階まで SSR も少し、それより深いと SR・SSR が多い）。持ち帰りは冒険の終わり（負けても受け取れる）。
- **装備のプリセット**: 今の装備を3組まで保存して、ワンタップで付け替えられます。
- **単語の強化（やり込み）**: 冒険の装備の「強化」か、ガチャの図鑑の単語カードから、**ガチャの交換ポイント**を使って1段ずつ +10 まで強化できます。
  +1 ごとに強さ +10%・効果 +8%。1段に使う交換ポイントは「レア度の基本（N 3・R 6・SR 15・SSR 40）× 段の倍率（1・2・3・5・8・12・18・26・38・55）」で、
  段が上がるほど重くなります（SSR は +5 まで 760、+10 まで合計 6,720。交換ポイントはガチャ1回で1つなので、相当やり込まないと届かない）。
  **+5 からアルティメット**: 効果がさらに1.5倍、SSR の特製の呪文が「極・」呪文（威力1.6倍・回復や吸収1.5倍）に。
- 進行と数値は `src/quest.js`（純粋関数。テストあり）、画面は `src/QuestScreen.jsx`。

### 単語ガチャ

単語の章の3000語を、ガチャで集めてコレクションします。

| レア度 | 対象 | 通常ガチャ | レアチケット | SR チケット | SSR チケット |
|---|---|---|---|---|---|
| N | 単語編・基礎 | 92.9% | 0% | 0% | 0% |
| R | 単語編・生活 | 6% | 100% | 0% | 0% |
| SR | 単語編・応用 | 1% | 0% | 100% | 0% |
| SSR | 語源・豆知識のある単語（62語） | 0.1% | 0% | 0% | 100% |

チケットは対象のランクの単語だけが出ます（レアチケット＝R、SR チケット＝SR、SSR チケット＝SSR）。

冒険限定の単語（36語）はガチャには出ず、冒険の宝箱からだけ手に入ります。

- **チケット交換**: レアチケット100枚 → SR ガチャチケット1枚、SR ガチャチケット100枚 → SSR ガチャチケット1枚。

- **全品詞／名詞／動詞／形容詞／副詞など** のガチャを選べます（品詞は章と日本語訳から推定、`POS_OVERRIDES` で個別に修正）。
- **ダブり進化**: 同じ単語が出ると Lv が上がり、フレームが銅（Lv.2）→ 銀（Lv.3）→ キラキラ（Lv.4 / MAX）に。
  意味・例文・語源・豆知識は1枚目から全部見られます。
- **MAX の単語もまた出る**: Lv.4（MAX）の単語もガチャに出続け、出たときは交換ポイントになります
  （いつもの1つに上乗せして N +2・R +5・SR +20・SSR +100）。引きまくった分は、単語の強化（冒険の「単語の強化」）に使えます。
  品詞ガチャでそのレア度の単語がないときだけ、その確率を1つ下のレア度に回します。
- 画面は「ポイント／レア／SR／SSR」の絵のタブで引くものを選び、品詞・確率・連数のボタンが1枚のカード（宝物庫の背景の絵）にまとまっています。
  チケット交換とルールの説明は、たたんだ箱の中です。
- **連数**: ポイントは 1回・10連・50連・100連・500連・1000連と「ポイントを全部使って引く」（一度に最大5000回）、
  レアチケットは 1・10・50・100連、SR / SSR チケットは 1・10連。
  50連以上は、レア度ごとの枚数と SSR・SR・NEW の単語をまとめて表示します。
- **救済**: 天井（通常ガチャ1000回で SSR 確定、未所持を優先）。10連などの確定枠はありません。
  引くたびに**交換ポイント**が1つ貯まり、図鑑から好きな単語と交換したり単語の強化に使ったりできます（交換はやり込み向けに N 200・R 800・SR 3,000・SSR 10,000）。
  以前配っていた**選択チケット**は今は配っていません（持っている分は図鑑でそのまま使えます）。
- **メダルとショップ**: ダブるとメダル（N 1・R 3・SR 10・SSR 30枚）。「ショップ」で5倍ブースト（150枚）・時止めの砂時計（40枚）・
  必殺技の巻物（60枚）と交換できます。
- **図鑑**は品詞（名詞・動詞・形容詞・副詞など）、レア度、獲得済み／未獲得で絞り込めます。
- **ポイント**: 学習（スワイプ）・シャドーイング・テスト・バトルは**取り組んだ時間に比例**（1分 約180pt。どれで遊んでも
  1分あたりほぼ同じになるようにしている。放っておいた時間はスワイプ1枚20秒・シャドーイング1文60秒・テスト1問60秒までで切る）。
  ほかに、はじめてボーナス 1000pt＋レアチケット1枚（1回だけ）、毎日のログインボーナス 300pt、今日の目標 900pt。
  （2026-09-29 に 1/10 に減らし、少なすぎたので 09-30 に3倍に戻しました）
- **コード**: 「コード」タブで英単語を入れるとポイントと、**その単語のカード**がもらえます（MAX・シークレット・冒険限定の単語はポイントだけ）。
  単語帳にある単語だけで、難しい単語ほど多い
  （N 100〜500・R 500〜1,500・SR 1,500〜3,000・SSR 3,000〜5,000・シークレット 5,000。最大 5,000pt。同じレア度なら長いほど上）。
  1日5回まで（間違いは数えない）、同じ単語は1回だけ。開発者コード `aaa` でポイント無限（「やめる」で戻せる）。
- **図鑑**: 未獲得の単語はシルエット（頭文字と文字数）と、SSR は豆知識の「チラ見せ」だけ。未獲得の単語は英語・意味では検索できません。
- **マイ称号**: 集めた単語を3つまで組み合わせて、自分だけの称号（例: Happy Robot）を作り、いつでも付け替えられます
  （30個まで）。つけた称号はガチャと進捗の画面に出ます。
- **実績とシークレット単語**: テーマの単語をそろえると実績（天体観測者など。以前の「称号」。図鑑の「実績」で見る）。語源のパーツが同じ単語を集めると、
  ガチャに出ないシークレット単語（companion・spectacular・unicorn）が解放されます。
- **演出**: 引くと光の玉がたまり、出たカードの一番いいレア度まで色が変わって（白→青→紫→金）はじけ、カードが1枚ずつめくれます。
  SR・SSR は溜めてからめくれて光ります。画面タップか「スキップ」ですぐ全部見られます（動きを減らす設定の端末では演出なし）。
- データは `src/data/gacha-data.js`（語源・豆知識、シークレット、称号）、ロジックは `src/gacha.js`（純粋関数・テストあり）。

### 採点（入力・音声で答えるとき）

英語 → 意味（日本語で答える）:

- 別解（`／` 区切り）や括弧の有無（「（考えて）理解する」→「理解する」）はどちらも正解
- カタカナ／ひらがな、全角／半角、記号や空白の違いは無視
- 少し言い回しが違う答えは「ほぼ正解」（文字の一致度で判定）として正解扱い

日本語 → 英語（英語で答える）:

- 大文字小文字・記号・短縮形（I'm = I am、gonna = going to、アポストロフィなしの im / dont も可）の違いは無視
- 見出しの `someone` は実際の人に、`my` は `your` / `his` などに置き換えても正解（give someone a ride → give me a ride）
- 小さなスペルミスや聞き違い（編集距離が長さの約2割まで）は「ほぼ正解」
- 頭文字ヒント（M___ s____）あり。答え合わせで正しい英語を自動で読み上げる

どちらも、判定が厳しいときは「意味は合っているので正解にする」で自己判定できます。

### 保存とログイン

- 進捗はまず端末（LocalStorage）に保存します
- **Google でログインすると、進捗をクラウド（Firebase）に保存**し、別の端末でも続きから学習できます。
  人ごとにアカウントが分かれ、他の人の進捗は見えません（Firestore のルールで保証）
- クラウド保存を使うには Firebase の設定が必要です → [CLOUD_SETUP.md](./CLOUD_SETUP.md)。未設定のあいだはログインボタンを表示しません

### 改修しても進捗が消えない仕組み

- 学習記録は問題IDに結びついています。ID は英語から作るため、英語を書き換えたときは
  [`src/data/id-changes.js`](./src/data/id-changes.js) に変更履歴を書きます。公開済みのIDは
  `src/data/ids.lock.json` に記録されていて、書き忘れると lint（CI）が止めます
- 今の教材にない問題の記録も捨てずに残すので、問題を一時的に外して戻しても記録は復活します
- 保存データの形を変えるときは、古い形から順番に移行する処理（`logic.js` の `MIGRATIONS`）を足します。
  移行の前には端末に `swipetalk:backup:v{版}` として元のデータを残します
- 新しい版のアプリで保存されたクラウドのデータは、古い版のページ（キャッシュなど）からは上書きしません

### 音声

- 読み上げは Web Speech API の `SpeechSynthesis`。**抑揚をつける**設定では文ごとに区切り、
  Yes/No 疑問文は語尾を上げ、WH 疑問文は控えめに、感嘆文は明るく速めに、`…` は低くゆっくり読みます。
  会話の A と B は別の声（なければ B を少し高い声）にします。
- 声の種類・話す速さは右上の ⚙️ から選べます。「Natural」「Google」「Premium」と付く声は抑揚が自然です。
- 会話の相手（B役）には、A役と性別の違う声を自動で選びます（⚙️ で変更可）。iPhone / Mac の
  おもしろ音声（Bubbles, Zarvox など）や旧式の合成音声（Fred など）は使いません（`src/voices.js`）。
- ブラウザの音声合成は SSML（感情・強調の指定）を解釈しないため、抑揚は pitch と rate の調整で近づけています。
  より人間らしい抑揚が必要なら、外部の音声合成サービス（有料 API）を使う必要があります。
- 音声で答える機能は `SpeechRecognition`（日本語）を使います。Chrome・Edge・Safari で動作し、
  マイクが許可されていない環境（Claude の Artifact 表示など）では入力か4択に切り替えられます。

### 日記

「日記」タブで、その日のことを自由に書きます（英語でも日本語でも）。気分を選べて、書くことに迷ったら「今日のお題」を押すと書き出しに入ります。
「保存する」で日付ごとに保存され（同じ日は上書き）、「これまでの日記」から見返せます。英語の日記は読み上げられます。採点はしません。

ただし成果物の `index.html` はコミットしてあり、実行時の依存はゼロ・`file://` で直接開けます。

## 開発

```bash
npm ci
npm run build        # src/ を変えたら必ず実行して index.html もコミットする
npm start            # http://127.0.0.1:8082/
npm test             # lint → ロジック → E2E
node tools/build.mjs --artifact /path/to/out.html   # Claude の Artifact 用に出力
```

`npm run lint` は `index.html` に埋め込んだ source-hash を検査するので、ビルドし忘れると CI が落ちます。

### 教材を追加・修正するとき

- 各章はちょうど 50 問（lint が検査）。ID は英語から自動で作られるため、同じ英語（大文字小文字・記号違いを含む）は重複として弾かれます。
- 英語を書き換えると ID が変わり、その問題の学習記録はリセットされます。
- 保存データ（LocalStorage `swipetalk:v2`）は読み込み時に教材と突き合わせるので、問題の追加・削除では壊れません。
  旧版（22フレーズ、`swipetalk:v1`）の「覚えた」も引き継ぎます。
