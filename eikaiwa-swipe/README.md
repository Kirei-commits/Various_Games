# SwipeTalk（スワイプ式 英会話フレーズ学習）

Tinder 風のスワイプで英会話フレーズを仕分けて覚え、テストで定着度を確かめるモバイルファーストの学習アプリです。
**全20章 × 50問 = 1000フレーズ**。`index.html` をブラウザで開けばそのまま動きます（サーバー不要）。

## 画面

| 画面 | 内容 |
|---|---|
| 学習 | 章を選んでカードを仕分け。右スワイプ（⭕️）で覚えた＝出題から外す、左スワイプ（❌）で最後尾へ。タップで日本語訳と A/B の会話例。PC では ← / → / Space でも操作可能。 |
| テスト | 出題範囲（各章・全章・苦手な問題）、問題数（10/20/50）、出し方（英語を表示／音声だけ）、答え方（入力／音声／4択）を選んで受験。間違えた問題は「未習得」に戻して学習カードの最後に追加し、「苦手な問題」に集めます。 |
| 一覧 | 1000件を英語・日本語で検索、章・習得状況で絞り込み。各行から音声再生、会話例の展開、覚えた／未習得の切り替え。 |
| 進捗 | 全体の習得率、連続学習日数、今日の学習数、累計スワイプ、テスト解答数、章ごとの進み具合とテスト最高点。 |

### 採点（入力・音声で答えるとき）

- 別解（`／` 区切り）や括弧の有無（「（考えて）理解する」→「理解する」）はどちらも正解
- カタカナ／ひらがな、全角／半角、記号や空白の違いは無視
- 少し言い回しが違う答えは「ほぼ正解」（文字の一致度で判定）として正解扱い
- それでも判定が厳しいときは「意味は合っているので正解にする」で自己判定できる

### 音声

- 読み上げは Web Speech API の `SpeechSynthesis`。**抑揚をつける**設定では文ごとに区切り、
  Yes/No 疑問文は語尾を上げ、WH 疑問文は控えめに、感嘆文は明るく速めに、`…` は低くゆっくり読みます。
  会話の A と B は別の声（なければ B を少し高い声）にします。
- 声の種類・話す速さは右上の ⚙️ から選べます。「Natural」「Google」と付く声は抑揚が自然です。
- ブラウザの音声合成は SSML（感情・強調の指定）を解釈しないため、抑揚は pitch と rate の調整で近づけています。
  より人間らしい抑揚が必要なら、外部の音声合成サービス（有料 API）を使う必要があります。
- 音声で答える機能は `SpeechRecognition`（日本語）を使います。Chrome・Edge・Safari で動作し、
  マイクが許可されていない環境（Claude の Artifact 表示など）では入力か4択に切り替えられます。

## 構成

```
index.html         ビルド成果物（CSS/JS をすべてインライン化した1枚）。直接編集しない
src/App.jsx        画面（React + Tailwind CSS + lucide-react）
src/logic.js       純粋なロジック: 教材の読み込み・採点・4択・抑揚・学習状態（DOM に触らない）
src/data/chNN.js   教材。1行 = 1問「英語 | 日本語訳 | 会話例（// 区切り） | 会話例の訳」
tools/build.mjs    esbuild + Tailwind CLI で index.html を生成
tests/lint.mjs     教材の形式・1000問・重複・index.html が最新かを検査（Node 標準のみ）
tests/logic/       採点・状態遷移・抑揚のテスト（node --test）
tests/e2e/         Playwright（desktop + mobile）。音声APIはスタブに差し替えて検証
```

他のゲームと違い、1000問の教材と React を使うため**ビルド工程があります**。
ただし成果物の `index.html` はコミットしてあり、実行時の依存はゼロ・`file://` で直接開けます。

## 開発

```bash
npm ci
npm run build        # src/ を変えたら必ず実行して index.html もコミットする
npm start            # http://127.0.0.1:8082/
npm test             # lint → ロジック → E2E
node tools/build.mjs --artifact /path/to/out.html   # Claude の Artifact 用に出力
```

`npm run lint` は `index.html` に埋め込んだ source-hash を検査するので、ビルドし忘れると CI が落ちます。

### 教材を追加・修正するとき

- 各章はちょうど 50 問（lint が検査）。ID は英語から自動で作られるため、同じ英語（大文字小文字・記号違いを含む）は重複として弾かれます。
- 英語を書き換えると ID が変わり、その問題の学習記録はリセットされます。
- 保存データ（LocalStorage `swipetalk:v2`）は読み込み時に教材と突き合わせるので、問題の追加・削除では壊れません。
  旧版（22フレーズ、`swipetalk:v1`）の「覚えた」も引き継ぎます。
