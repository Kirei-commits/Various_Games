# AI組織ボード

CEO役のAI（アカリ）が、部署ごとのAIメンバー16人に指示を出し、
SNS投稿が「リサーチ → 執筆 → 画像 → 審査 → 予約・投稿」と流れていく様子を眺めるシミュレーションです。
単一の `index.html` だけで動きます（ビルド不要）。

## 遊び方

- `index.html` をブラウザで開く。06:00 に CEO が全員へ一斉指示を出し、仕事が回り始めます。
- 右上の「指示を出す」で今日のテーマを変えられます（これから作る投稿のタイトルに反映）。
- 時間の速さは ×10 / ×60 / ×240 / ×900、❚❚ で一時停止。

## 中で起きていること

| 部署 | やること | 使う道具 |
|---|---|---|
| リサーチ | 伸びた投稿・ネタ・数字の裏取り | Playwright |
| 執筆 | 1行目5案、本文、長めの記事 | （Claude 自身） |
| 画像 | 画像・サムネ・動画 | 画像生成AI |
| 審査 | 20項目チェック、AIっぽさ消し。約2割を差し戻す | 別のAI |
| 予約・投稿 | 枠に予約、時間どおり投稿、返信 | xlsx / launchd / X API / Threads API |
| 分析 | 朝7時の報告、伸びた型レポート、遅れた投稿の救出 | X API / xlsx |

- 1日 70 本を 07:30〜23:00 に 11 アカウントへ割り振り。投稿の2時間半前から制作を始めます。
- 予定時刻までに審査を通らなかった投稿は「遅延」として救出され、予約後すぐに投稿されます。
- 仕事を終えるたびに経験値が入り、メンバーのレベルが上がります。日付が変わると次の DAY へ。

いまはすべて画面内のシミュレーションで、実際の API には接続していません。
