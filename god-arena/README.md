# GOD ARENA — 神器大戦

神から授かった神器を撃ち合う、属性つきの多人数バトル。
ゴッドフィールドのような「引いた武器で殴り、属性の合う防具で受ける」遊びを、
ブラウザだけで完結する形にしたものです。

`index.html` をブラウザで開けばそのまま動きます。ビルドも実行時の依存もありません。

## ルール

- 最後のひとりになるまで戦います（1〜5人の相手と対戦）。
  HPは 2人なら48、**人数が増えるごとに +6**（全員が必ず攻撃するので、人数分の火力が集まる）。
- **先手は毎回ランダムに決まります。** 手番順には有利不利が残っていて、
  人間をいつも先頭に置くとその偏りをいつも人間が背負うことになるためです。
- **1対1では後に動く側が神器を1つ多く持って始まります。** 先に動く側は1回多く
  攻撃できるぶん有利になるためです（補正前 54.7% → 補正後 49.7%）。
- **神の怒り** — ラウンド18を過ぎると、通ったダメージがラウンドごとに重くなります
  （最大2.5倍）。長引いた勝負を畳むための仕掛けで、6人戦の最長が
  ログ448件 → 301件に縮みました。ふつうの長さの勝負には効きません。
- **神の加護** — 残りHPが4割以下になると、受けるダメージと撃ち返しが**半分**になります。
  集中砲火されても手番が回るようにするための救済で、**どくには効きません**（とどめの手段が残る）。
- 手番でできることは3つのうちひとつ。
  - **こうげき** — 武器を1つ以上えらんで相手を狙う。複数まとめて撃てます。
  - **つかう** — 食料で回復、魔法で補充・強奪。
  - **いのる** — 神器を3つ授かる。**武器を持っている間は祈れません**（攻め手があるのに引き直せない）。
- **攻撃は同じ属性の防具でしか止まりません。** `全` の防具だけは何でも受けられます。
  - 例: 火14 の攻撃に 水9 の盾を出しても 14 くらう。火9 の盾なら 5 で済む。
  - だから **属性を混ぜて撃つほど防がれにくい**。火6+雷10 は 火9 の盾では 10 通る。
- 防具の余りは他の属性に回りません。過剰な防御は無駄になります。
- **武器の特性**。同じ火力でも当たり方が違うので、どれを撃つかに意味が出ます。
  | 特性 | 効果 |
  |---|---|
  | 連撃 N | N回に分かれて当たる。**防具1枚が受け止められるのは1回分だけ**。大きな盾1枚で受けきれない |
  | 貫通 | 防具の効果が**半分**になる |
  | 会心 | その一撃が**1点も防がれなければ威力1.5倍**。属性を読み切れたご褒美 |
  - 特性つきは素の武器より火力が低めです。火力と当たり方を引き換えにしています。
- **反射具**（かがみのたて等）で受けると、**止めた分をそのまま撃ち返します**。
  撃ち返しは防げません。大技を1属性に寄せると、そのまま自分に返ってきます。
  - 相手を倒した攻撃が撃ち返しで自分も倒す **相打ち（引き分け）** が起こります。
- **状態異常**を魔法でかけられます。相手カードに残りターン数つきで出ます。
  | 状態異常 | 効果 |
  |---|---|
  | どく ☠ | 相手の手番のはじめに毎ターンダメージ（3ターン） |
  | ふうじ ⛔ | 相手の**手札でいちばん強い属性**を封じる。攻撃も防御もできなくなる（2ターン） |
  | のろい ✖ | 相手の**防御力と反射量を半分**にする（3ターン） |
  - ふうじの対象は手札から決まるので、かける側にも「どこに当たるか」は見えません。
    必ず痛いところに当たるが、狙って当てることはできない効果です。
- 相手カードには、その相手が**これまでに防いだ属性（厚）と素通しした属性（薄）**が出ます。
  AI が使っているのと同じ情報なので、同じ土俵で読み合えます。
- 手札は12枚まで。上限で祈ると、価値の低いものから捨てて新しい神器が入ります。

## 画面

**一画面に収まります。** スクロールするのは手札だけで、相手・ステージ・操作列は
常に見えています。戦況ログ・属性表・戦績は 📜（キー `L`）で引き出します。

攻撃の結果は**属性ごとの内訳**で出ます。「何ダメージ」だけでは、どの属性が
防げてどれが通ったのか読み取れないためです。受ける前のプレビューと
解決後の結果で同じ形を使うので、防具を選び直しながら確かめられます。

```
アレス の ごうか + れんらい + つらぬきやり
🔥火  ████████████████   14 → 14
⚡雷  ██████████░░░░░░    9 →  9
◇無  ████▌░░░░░░░░░░░    6 →  1   防 5
このまま受けると 24 ダメージ（5 防いだ）
```

帯の長さは属性ごとの量を表します（青 = 防いだ / 緑 = 撃ち返した / 赤 = 通った）。

狙う相手は **🎲 ランダムに狙う**（キー `R`）でも決められます。
武器を選んだ状態で押すと、そのまま攻撃まで進みます。
食料や回復は勝手に使いません。

## 属性

| 属性 | 無 | 火 | 水 | 雷 | 光 | 闇 | 全 |
|---|---|---|---|---|---|---|---|
| 記号 | ◇ | 🔥 | 💧 | ⚡ | ✦ | ☾ | ✳ |

`全` は防具にしか付きません（反射具に付けると受け一択になって成立しません）。

## 相手の強さ

| 難易度 | 中身 |
|---|---|
| かけだし | 評価がぶれる。受け損なうこともある |
| ベテラン | 過剰攻撃を避け、だいたい正しく防ぐ |
| ゴッド | 相手がこれまで何を防いできたかを読み、通りやすい属性を突く。反射の危険も見積もる |

実測（撹拌シードでタイマン600局・先後入れ替え）:

| 対戦 | 勝率 |
|---|---|
| ゴッド vs かけだし | 73.7% ±3.5pt |
| ベテラン vs かけだし | 64.4% ±3.8pt |
| ゴッド vs ベテラン | 58.1% ±4.0pt |

1局の手数は中央値 38〜40手。相打ちは 1% 前後です。
多人数戦の公平さ（撹拌シード各150〜300局）:

| 人数 | 最初の脱落までの手番数（中央） | 一度も動けず退場 |
|---|---|---|
| 2人 | 15手 | 0% |
| 4人 | 10手 | 0% |
| 6人 | 12手 | 0% |

（対策前は 4人・6人とも中央 **1手**、6人戦では4人に1人が**一度も行動できずに**退場していました）

1局の長さ（撹拌シード各400局・ログの件数）:

| 人数 | 中央 | 9割 | 最長 |
|---|---|---|---|
| 2人 | 41 | 68 | 123 |
| 4人 | 116 | 144 | 183 |
| 6人 | 203 | 237 | 301 |

手番順による勝率の偏りは残っています（3人戦では後に動く側が 37.7%／期待33.3%、
撹拌シード1200局）。原因は「攻撃すると手札が減り、手札の薄い相手ほど狙われる」
ことで、早く動いた者が序盤に多く殴られます（初回被弾は4人戦で 21.7 対 11.7）。
狙いの重みを下げても勝率の偏りは改善しなかったため、**先手をランダムに決める**
ことで、その偏りを特定の席が背負わないようにしています。

## URLで対戦条件を指定する

不具合の再現やテストのために、クエリで上書きできます。

```
index.html?seed=42&speed=fast&opponents=3&level=hard&sound=off
```

`seed` を固定すると、引きも AI の判断も同じ展開になります。

## 開発

```bash
npm ci               # 開発用の依存（Playwright のみ）
npm start            # http://127.0.0.1:8081/ で配信
npm run lint         # 構文・参照・読み込み順・アイテム定義の検査
npm run test:logic   # ルール・AI・永続化（Node標準のテストランナー）
npm run test:e2e     # ブラウザテスト（デスクトップ + スマホのタッチ）
npm test             # 上記すべて
npm run playtest     # 実ブラウザで通しプレイ（詰み・停止・表示崩れを探す）
npm run shots        # 主要画面を撮る（一画面に収まっているかの確認）
```

`npm run playtest` は決められた局面を確かめるテストと違い、**最後まで実際に遊んで**
壊れ方を探します。`--games 5` で局数を増やせ、`--keep` でスクリーンショットが残ります。
