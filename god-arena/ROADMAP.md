# ROADMAP — 対戦を面白くしていく順番

このファイルは**自動改善ループの記憶**です。各回のはじめにここを読み、
上から未着手のものを取り、終わったら「やったこと」へ移します。

判断の基準はひとつ、**「対戦が楽しくなるか」**。
楽しさの中身を分解すると、この4つのどれかが増えることを指します。

1. **選択の意味** — どの手を選んでも同じ、にならない
2. **読み合い** — 相手の手札や狙いを推測して外す余地がある
3. **逆転の余地** — 不利からでも戻せるが、運だけでは戻らない
4. **手触り** — 何が起きたかが一目でわかる

### v1.2 — 状態異常と難易度の測り直し（2026-09-12）

### v1.4 — 通しプレイの導入と、多人数戦の公平さ（2026-09-12）

**「実際に遊んでみる」を仕組みにした**（`npm run playtest`）。
実ブラウザで決着まで遊び、詰み・停止・表示崩れ・JSエラーを探す。
これで初回から本物の問題が出た。

- **同じ相手を2連続で攻撃できなかった**（狙い先が残るため、もう一度タップすると
  選択解除になっていた）→ 選んでいる間の再タップは「そこへ撃つ」の確定に変更
- **多人数戦で何もできずに退場していた**。対策前は4人・6人戦とも最初の脱落者が
  動けた手番数の中央値が **1手**、6人戦では4人に1人が**一度も行動できず**に消えていた。
  原因は「武器を持っていたら必ず攻撃」で人数分の火力が1人に集まること。
  - **神の加護**（残りHP4割以下で被ダメージと撃ち返しが半減。どくには効かない）
  - **人数に応じたHP**（2人48、以降+6）
  - **AIが集中砲火を避ける**（瀕死を優先せず、そのラウンドで殴られた相手を避ける）
  → 実測: 4人戦 中央10手 / 6人戦 中央12手 / **一度も動けず退場 0%**
- **演出の待ちが取りこぼされる場面を捕まえた**（setTimeout と rAF の両方が来ない）。
  待ちを二重化し、5秒動かなければ世代番号を上げて自力復帰する
- セルフレビュー（/code-review）で5件の実バグを検出して修正
  - 新対局で世代を上げておらず、前の対局の処理が新しい局面を触る
  - 全属性の防具が、その属性しか止められない防具の出番を奪う（並び順で結果が変わる）
  - プレビューの撃ち返しに加護が効いておらず、実際とずれる
  - `drive()` が世代を見ておらず、復帰後に二重に進行しうる
  - AIの攻撃見積もりが加護を無視し、倒せない相手に手札を使い切る
- 実測（撹拌シード600局）: ゴッド vs かけだし **72.9%**、ベテラン vs かけだし 64.0%、
  ゴッド vs ベテラン 59.0%。手数中央38〜40手
- ロジック100件 / E2E80件 / 通しプレイ9局 0 issues
