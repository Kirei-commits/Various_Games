# ROADMAP — 対戦を面白くしていく順番

このファイルは**自動改善ループの記憶**です。各回のはじめにここを読み、
上から未着手のものを取り、終わったら「やったこと」へ移します。

判断の基準はひとつ、**「対戦が楽しくなるか」**。
楽しさの中身を分解すると、この4つのどれかが増えることを指します。

1. **選択の意味** — どの手を選んでも同じ、にならない
2. **読み合い** — 相手の手札や狙いを推測して外す余地がある
3. **逆転の余地** — 不利からでも戻せるが、運だけでは戻らない
4. **手触り** — 何が起きたかが一目でわかる

## やったこと

### v1.0 — 基礎の対戦（2026-09-11）
- 属性ダメージ計算（同属性の防具でしか止まらない／`全` は何でも受ける）
- 1〜5人の乱戦、HP40、手札12枚
- 攻撃・防御・祈り・食料・魔法（回復／天啓／強奪）
- 3段階のAI（期待ダメージの見積もり、相手の防具をログから読む）
- 「武器を持っている間は祈れない」で膠着を解消
- lint / ロジック43件 / E2E44件 / 2プロジェクトCI

### v1.1 — 反射と読みの可視化（2026-09-11）
- **反射具** 6種（無・火・水・雷・光・闇）。止めた分をそのまま撃ち返す。撃ち返しは防げない
- 同属性に反射具と防具が重なったら反射具を先に充てる（撃ち返しが最大になる配分）
- **相打ち（引き分け）** を正式な決着として実装。反射で攻撃側も倒れる
- 相手カードに **厚／薄の帯**。`AI.readDefenses()` の結果をそのまま人間にも見せる
- AIは反射されそうな量を見積もって大技を寄せすぎない（`expectedReflect`）
  → ゴッド vs かけだし 70% → **77%** に伸びた
- ロジック56件 / E2E54件

### v1.2 — 状態異常と難易度の測り直し（2026-09-12）
- **どく**（毎ターンダメージ）／**ふうじ**（手札で最強の属性を封じる）／
  **のろい**（防御力と反射量を半分）。殴る以外の脅し方が入った
- ふうじの対象は engine が相手の手札から決める。かける側には見えない
- 狙い先つきの魔法は、武器と同じ「選ぶ→相手をタップ」の操作に統一
- 封じられた手札は消さず「封」を付けて残す（持っているが出せないことが分かる）
- **難易度の測り方の誤りを修正。** 等差シードで測っていたため乱数列が相関し、
  同じ実装で勝率が 61% と 73% に分かれていた。`mixSeed()` で撹拌して測り直し、
  `AI.LEVELS` を実測ベースで再調整
  （ゴッド vs ベテランが 52.8% → **58.0%** に。序列が正しく分離した）
- ロジック69件 / E2E66件

## つぎにやること

### A. 読み合いを深くする（ひととおり完了）

### B. 選択の意味を増やす（次はここ）
- [ ] **武器の特性** — 連撃（複数回判定）、貫通（防具を半分無視）、
      会心（低確率で倍）。同じ火力でも選ぶ理由が変わる。
- [ ] **祈りの選択** — 3つ引くか、1つだけ狙って引くか（属性を指定して確率を上げる）。
- [ ] **捨てる操作** — 手札上限で何を捨てるかを人間が選べるようにする。

### C. 逆転の余地
- [ ] **神の気まぐれ** — 数ラウンドごとに全体イベント（全員回復／全属性無効／
      手札シャッフル）。長期戦が単調にならないようにする。
- [ ] **瀕死ボーナス** — HPが低いほど祈りの質が上がる。負けが決まった側が粘れる。

### D. 手触り
- [ ] **攻撃の演出** — 攻撃側から対象へ属性色の軌跡を飛ばす。誰が誰を撃ったか一目で。
- [ ] **ダメージ内訳の表示** — 「火14のうち9を防いだ」を属性ごとに見せる。
- [ ] **リプレイ / 棋譜** — `?seed=` と組み合わせて1局を再現・共有できるようにする。
- [ ] **チュートリアル** — 初回起動時に属性の相性だけを教える3画面。

### E. 対戦の幅
- [ ] **2人プレイ（同一端末）** — 手札の受け渡し画面を挟む。
- [ ] **チーム戦** — 2対2。味方への回復と、誰を守るかの判断が生まれる。
- [ ] **サバイバル** — 連戦でHPと手札を持ち越す。

## 進め方の決まり

- 1回のイテレーションで **A〜E のどれか1つ**を仕上げる。中途半端に広げない。
- 仕上げる = **ルール実装 + ロジックテスト + E2E + ドキュメント更新 + CI緑**。
- ゲームバランスを変えたら、`tests/logic/ai.test.mjs` の
  難易度・試合長のテストを必ず測り直す（数値もテストに書き直す）。
- 迷ったら「選択の意味・読み合い・逆転・手触り」のどれが増えるかで決める。
