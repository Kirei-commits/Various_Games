### おすすめの順番
**A → B → C → D**。理由：A は画面より前に必要な Core の最後の塊で、dotnet だけで検証できる。B は A と独立なので、A の合間に進められ、再 calibrate もまとめて1回で済む。C は小さく、いつでも差し込める。D は Unity が要るので、PC か GameCI の用意ができたときに。E・F はその先（フェーズ3〜5）。

## 5. ユーザーに決めてほしいこと（進める前に）
1. **Unity の環境**：PC の Claude Code で進められるか、クラウド（GameCI）で APK をビルドするか。D の前に必要。
2. **覚醒の素材とレベルアップの費用**（docs/01 11節 #17）：仮に覚醒の欠片で払う。レベルアップの経験値の入手元（放置報酬・試練）をどう置くか。A の②に入る前に確認したい。
3. **記憶カードの数値**（docs/01 7.2節 `[実測＋仮]`）：仮のままで進めてよいか。
4. **放置報酬の上限**（`system.idleCapHours` = 24）：このまま進めてよいか。
5. 70％ラインのランク10〜15：ラインを緩める（10％ → 20％）か、敵の専用スキルを入れて直すか（B の⑤）。
