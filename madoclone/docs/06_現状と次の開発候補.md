### おすすめの順番
**A → B → C → D**。理由：A は画面より前に必要な Core の最後の塊で、dotnet だけで検証できる。B は A と独立なので、A の合間に進められ、再 calibrate もまとめて1回で済む。C は小さく、いつでも差し込める。D は Unity が要るので、PC か GameCI の用意ができたときに。E・F はその先（フェーズ3〜5）。
