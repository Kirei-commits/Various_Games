# 成長速度・攻撃スピード・レース周回・闘技シーズン（2026-11-16、ユーザー回答）

ユーザーが「1・2・3は推奨でOK」「4は30戦＝1シーズン、報酬はおまかせ、順位表は自分の前後5人＋全順位のスクロール」「5はジェムとチケットだけ、ステップ報酬は既存と同じ」と回答した。

## 1. 成長速度の倍率（推奨どおり）
- 設定の `growthSpeed`（整数 1〜5）。**収入と待ち時間だけ**に掛け、戦闘の強さは変えない。
- 掛ける先：放置報酬（経験値・コイン・絆ハート・ワイン。時間の上限は変えず量に掛ける）、試練の回数が貯まる速さ（RepeatGate）。
- 変える前に、放置報酬を受け取り、試練の回数を元の速さで確定させる（過去にさかのぼって倍にできないようにするため）。

## 2. 攻撃スピード（推奨どおり）
- 研究所ツリーに `lab_aspd_01〜06`（ステータス `attackSpeedPct`、1Lvあたり +1％、最大5Lv、6本）を足した。全部上げて +30％。
- タロット（5つの効果）には足さない（`docs/01` は「研究ツリーにまとめ、攻撃スピードもここで上げる」）。上限 `attackSpeedMax` 5.0 は不変。
- 校正（70％ライン・ボス勝率）は、研究を使わない標準プロファイルで行っているので影響しない。

## 3. レースの周回（推奨どおり）
- 実績に `lapScale`（1.2）を持たせた。全部の段を受け取ると次の周へ進み、目標が ×1.2（切り上げ）になる。最後の目標を超えた分は次の周に持ち越す。
- `race_familiar`（使い魔の力）と、新しい `race_lab`（研究メモの消費。10段、ジェムと、3段ごとに功績メダル）。
- NPC ライバル20人との追い抜きは作らない（闘技の順位表と同じ仕組みを後で使い回せる）。

## 4. 闘技のシーズン（ユーザー指定）
- 1シーズン＝**30戦**（挑戦するたびに1戦。掃討は数えない）。勝つと +100、負けると −40（0未満にならない）。
- 順位は、NPCライバル100人との比べ合い。ライバルのポイントは「シーズン番号＋番号」から決まり（保存しない）、シーズンの進みに比例して増える（最終 0〜2800）。同点は自分が上。
- シーズン終了で最終順位を受け取り待ちにして、次のシーズンを 0 点から始める。受け取る前に次が終わったら、前の分は自動で受け取る。
- 報酬（おまかせ。`guild.json` の `arena.rewardTiers`）：1位 ジェム3000＋チケット100、3位以内 2000＋60、10位以内 1200＋40、30位以内 700＋20、60位以内 400＋10、それ以外 200＋5。
- 画面：ギルドの「順位」タブ。自分の前後5人と、全順位（スクロール）を切り替える。

## 5. イベント
- 期間限定のイベント・イベント通貨（羊）は作らない。ジェムとチケットだけ。ステップ報酬は既存のガチャのもの（100〜1,500回ごと）と同じ。
