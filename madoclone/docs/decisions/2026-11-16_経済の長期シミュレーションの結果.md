# 経済の長期シミュレーションの結果（2026-11-16）

`dotnet run --project tools/Mado.Sim -c Release -- economy --real --days N --hours-x10 H [--every K]`（`--real` は強さの代用品を使わず、広場・竜の巣・研究・霊石版・記憶カードなど本物の育成だけで強くなる遊び手。1日 H/10 時間遊び、残りは放置）。

## 分かったこと
- **ランクの進み（本物の育成、1日2時間）**：ランク4＝3日、12＝10日、16＝16〜21日、20＝25〜32日、21＝40日。ランク13〜15で一度ゆっくりになる（70％ラインを緩めない方針どおり）。
- **1日1時間**：ランク12＝20日、22＝55日、23＝90日。1時間でも2時間の6〜7割の速さで進む（放置報酬と回数の持ち越しが効く）。
- **ランク22〜23 付近で止まる**：遊び手は★11・Lv120（上限）に着き、素材の入りと使い道は釣り合っている（コイン・ジェム・チケット・経験値・星の砂・竜の炎は9割以上使われる）。それでも先に進まないので、ここから先は育成の天井（広場・竜の巣・霊石版・タロットの上限）が敵の強さに足りているかの調整が要る。**最終ボス（ランク32）は100日では倒せていない**。
- 強さの代用品（`RankProfileSource`）を使うと、1日2時間でランク29まで25日で着く。校正の「標準」は、本物の育成より甘い。

## 直したこと
- 使い道の無かった通貨に、交換所の項目を足した：竜の力1,000→覚醒の欠片10、魔力の欠片1,000→星の砂500、功績メダル10→覚醒の欠片10。
- 遊び手に、霊石版の装備・強化、交換所、タロットの上位への入れ替え、チケットの使い切りを足した（これで素材の使われ方が実際に近づいた）。

## まだ分かっていないこと・次
- ランク22以降の壁が、遊び手の賢さの不足か、育成の天井の不足かは未切り分け。天井側なら、`research.json` などの上限か、`difficulty.json` の敵の強さ（`enemyStatShare`）を見直す。ユーザーの判断も要る（「最終まで何日かかってよいか」）。
- 遊び手が使っていないもの：記憶カードの個別の選び、リーダー属性、サポートの選び、図書館・ギルド系の報酬。
- 長い実行は重い（40日で約10分。試練の挑戦が主）。
