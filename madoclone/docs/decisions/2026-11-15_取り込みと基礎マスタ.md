# 2026-11-15 取り込みと基礎マスタで決めたこと

- **取り込みと検証は、いまは Python（`tools/bootstrap/`）**。作業した環境に .NET と Unity が無かったため。取り込みは一度きりなので C# に書き直さなくてよい。検証（validate.py）は、Mado.Sim validate ができたら置き換える。
- **レベル表は実測の「形」だけ使い、Lv1 を基本値（攻撃力225・HP 8,500・防御力60）に合わせ直した**。仕様書4.6節の実測値は「全体強化が乗った後の値」（Lv1でHP 15,671k）。これをそのまま基礎にして 6.4節の式で全体強化を掛けると二重になる。\[仮\]：基本値は仕様書4.1節のURアタッカーの値。
- **段階が書かれていないバフは `tier: null` のまま取り込み、`needsReview` を付けた**（138か所）。勝手に最上級にはしない。まとめて決めるなら、ユーザーに「段階なしは何級として扱うか」を聞く。
- **防御・回復・妨害のロール倍率に仮の値を入れた**（防御 0.6／1.4／1.5、回復・妨害は攻撃0.9）。全部1.0だとタンクが硬くならない。`provisional: true` 付き。
- **スキル名は付けていない**。元の技名は `dev/sourcemap.json` にだけ入れた。ゲーム内の技名は後で自作する。
- **「天竜の加護」は buffId `blessing_regen`** にした（表示名は後で自作）。
- **取り込み後は JSON が正**。`import_characters.py` と `gen_masters.py` を流し直すと JSON を上書きするので、手で直したあとは流さない。
