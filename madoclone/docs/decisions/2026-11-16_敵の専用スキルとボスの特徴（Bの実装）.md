# 2026-11-16 敵の専用スキル・ボスの特徴・最終ボス（B）と再 calibrate

## 実装
- **`enemy_kits.json`**（データ。コードに埋めない）：敵専用スキル12本（skills.json と同じ trigger・effects の形。`CheckBody` で同じ検証）、型ごとの専用スキル（`roleSkills`）、ボスの特徴（`traits`）、ランクごとの割り当て（`bossPlan`）、最終ボスの特徴（`finalBossTraits`）。検証は `ENEMY_KITS`。
- **型ごとの専用スキル**（雑魚・ボス戦の全員）：アタッカー＝8秒ごとに範囲140％、タンク＝6秒ごとに**挑発**（相手全員）＋自分に防御アップ、回復役＝5秒ごとに最もHPの低い味方を回復（攻撃力の300％）＋12秒ごとに状態異常の解除。敵は魔晶を持たないので、**魔晶の枠にスキルを足す**形にした（エンジンは変えていない）。
- **ボスの特徴**（ボス本体1体だけ。docs/01 6.1節の表）：ランク4〜6 治癒禁止＋沈黙（10秒ごと）／7・8・9 属性耐性（ダメージ半減。属性はランクごとに違う）／10〜12 高クリティカル（率＋40、ダメージ×1.5）／13〜15 高命中・高火力（命中＋30、攻撃×1.3）／16〜18 行動阻害バリア常時／19〜21 高回避（＋25）／22〜24 10秒ごとに自分のデバフ解除＋攻撃アップ／25・26 バリア＋高回避／27・28 解除＋高クリティカル／29〜32 高クリティカル＋高命中＋解除＋HP半分で攻撃アップ。
- **属性耐性**（エンジンの唯一の変更）：`UnitSetup.ResistElement`／`ResistMultiplier`。攻撃側の属性が耐性の属性なら、ダメージに倍率を掛ける（属性の有利・不利の倍率と別に掛ける）。
- **最終ボス**（ランク32の 10-10。`StageFactory.IsFinalBoss`）：制限時間 180 秒。段階1＝8秒ごとに敵全体へ600％。段階2（HP66％以下で1回）＝行動阻害バリア。10秒ごとに自分のデバフを解除。段階3（HP33％以下で1回）＝攻撃・命中アップ＋敵全体へ800％＋沈黙。**[仮]の簡略化**：解除は段階2に入る前から10秒ごとに動く（エンジンに「HPが一定以下の間だけ」の発動が無いため）。
- 見つけたバグ：`BattleStats` は struct なので、取り出して書き換えても戻らない。ボスの特徴の補正が最初は効いていなかった（テストで「特徴の分だけ上乗せされている」を確かめて発見）。直して、再 calibrate した。

## 70％ラインの解消
- 専用スキルとボスの特徴だけでは、ランク10〜15 の「推奨の70％でボス勝率10％未満」は満たせなかった（13〜26％）。
- **敵の防御の配分（`enemyStatShare.def`）を 0.0058 → 0.058 に上げて**満たした。勝率と戦力の関係の**崖**（ダメージ＝攻撃−防御）が急になる。0.0232（4倍）では 13〜23％、0.058（10倍）で全ランク 0.5〜5.5％。
- 副作用はよい方向：**敵のHP倍率が最大 458倍 → 136倍**に下がった（防御で耐久を稼ぐ分、HP を盛らなくてよくなった）。

## 気になる点（次の調整）
- ランク27〜32 の敵の**攻撃倍率が 0.01〜0.17 と極端に小さい**。ボスの特徴（高クリティカル＋高命中＋攻撃アップ）と、最終ボスの全体攻撃が強く、倍率で打ち消している。特徴の強さ（クリティカル＋40・攻撃×1.3 など）を弱めるか、倍率の下限を決めて特徴を調整するのが次。
- ランク1〜3 のHP倍率が1未満（0.25〜0.7）。`enemyStatShare.hp` が序盤で多すぎる。
- 「回避・命中ダウン編成なら推奨の半分でも勝てる」「ランクの境目で勝率が不連続にならない」は未検証。
