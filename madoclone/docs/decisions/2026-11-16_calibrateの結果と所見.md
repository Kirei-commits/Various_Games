# 2026-11-16 calibrate（敵の強さの自動合わせ）の結果と所見

`dotnet run --project tools/Mado.Sim -- calibrate --write`（1ランク200戦、約2分）で、`sim_profiles.json`（32ランク分の標準編成と共通倍率）と `difficulty.json` の `enemyScale` を書き込んだ。

## やり方
- **編成**（`SimPolicy`）：そのランクで解放済み（`tiers.json` の unlockRank 以下）のキャラから、役割をばらして7体（ランク1〜3は3〜5体、4以降は6体＋リーダー）。格の倍率が高い順・ID の順。★は 01 6.1節の「想定★」、Lv は★の最大 Lv。
- **共通倍率**：編成の戦力 ＝ ランクボス（10-10）の推奨戦力 になる倍率（攻撃・HP・防御に同じ値）。副ステータスの標準値（回避 5＋2.5r など）は**まだ入れていない**（docs/04 8.2節のとおり Global の輪だけ）。
- **敵の倍率**：推奨ちょうどのボス戦（敵の合計戦力 ＝ 推奨 × 0.8）で、攻撃倍率を二分探索して勝率 80％に、HP 倍率を二分探索して「勝った戦闘の決着の中央値」30 秒に合わせる。これを4周くり返す。

## 結果（合格ラインとの突き合わせ。docs/02 6.5節）
| 項目 | 結果 |

| 勝つ戦闘の決着 20〜40 秒（ボス） | 29〜30 秒 ✓ |
| 雑魚ウェーブの勝率 95％以上 | 全ランク 100％ ✓（決着は9〜11秒。合格ラインの 3〜10 秒より少し長いランクがある） |

## 所見
- 敵の攻撃倍率は 1.5（ランク1）→ 0.08（ランク32）と**大きく下がる**。副ステータスの標準値を味方に入れていないため、敵の副ステータス（命中・クリティカルの式）が相対的に強すぎ、攻撃倍率で打ち消している。味方の副ステータス（回避 5＋2.5r、命中 100＋1.5r、クリ耐性 2r、クリ防御 250r、クリダメ 600r）を `ProfileModifierSource` の Flat として足すと、倍率が1に近づくはず。次にやるなら、これが先。
- ランク6〜15で「70％でも勝てる」のは、勝率と戦力の関係に**崖**があるため（ランク10：戦力比 1.0→80％、0.85→70％、0.7→65％、0.5→0％）。ダメージが (攻撃 − 防御) で決まるので、一定以下で急に与ダメージが落ちる。ラインを満たすには、敵の防御の配分（`enemyStatShare.def`）か、副ステータスの入れ方を見直す。
- 敵の専用スキル（挑発・回復・状態異常）はまだ無い。入れたらもう一度 calibrate を流す。
- このバランスは戦闘ルール・スキルのデータ・難易度を変えると崩れる。`CalibrationTests`（ランク1・8・16・32のボス勝率 65〜95％）が落ちたら、`calibrate --write` で合わせ直す。

## 追記（同日）：味方の副ステータスの標準値を入れて再校正した
`sim_profiles.json` に `allySubstats`（A + B×ランク。回避 5＋2.5r、命中 100＋1.5r、クリ率 15＋4r、クリダメ 600r、クリ耐性 2r、クリ防御 250r。docs/01 6.2節の表）を置き、`ProfileModifierSource` が**基本値より大きい分だけ** Flat で足す。標準値が基本値より小さいランクでは何も足さない。

| 項目 | 副ステータスなし | あり |
| --- | --- | --- |
| ボス勝率 | 77〜85％ | 75〜85.5％ |
| 決着（勝った戦闘） | 29〜30 秒 | 29〜30 秒 |
| 推奨の70％でボス勝率 10％未満 | ランク6〜15が未達（35〜65％） | **ランク10〜15のみ未達（13〜17％）**。1〜9・16〜32 は ✓ |
| 敵の攻撃倍率 | 1.5 → 0.08（大きく下がる） | 1.3〜5.5（おおむね 2.5 前後で安定） |
| 敵の HP 倍率 | 1〜4 | 3〜445（ランクが上がるほど大きい） |

- 敵の攻撃倍率が 1 の近くに戻ったので、前回の仮説（副ステータスの不足を攻撃倍率で打ち消していた）は当たっていた。
- 代わりに **敵の HP 倍率が 445 倍まで上がった**。味方のクリティカルが効くようになり、docs/01 6.2節の見直し（「ボスのHPは戦力から決めると桁が足りない」）が示す状況になった。HP の配分（`enemyStatShare.hp`）を戦力の比率から切り離して持つ設計にするかは、フェーズ1の後半で決める。
- ランク10〜15は、70％でも13〜17％勝つ。2つの倍率（攻撃・HP）で「勝率80％」「決着30秒」を決めているので、戦力に対する勝率の傾きは動かせない。傾きを急にするには、敵の防御の配分（`enemyStatShare.def`）か、敵の専用スキルを動かす必要がある（未着手）。
