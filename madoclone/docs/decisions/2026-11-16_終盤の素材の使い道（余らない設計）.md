# 終盤の素材の使い道（余らない設計）（2026-11-16）

ユーザーの指示：「記憶カードは装備するもの以外はその場でアイテムに還元されるので溜まらない設計に」「終盤素材が余らないように、エンドコンテンツのように（経験値はリーダー強化で重く、星の砂はレベルごとに要求量が上がり、ワインはタロットを交換する回数で量が変わる、など）」。

## 決めたこと

| 素材 | 使い道（追加・変更） |
|---|---|
| 記憶カード（持ち物） | 絆ガチャで引いた瞬間に判定する。**いま付けているカードより強い**（かつ自動絆ガチャの条件に合う）カードだけ、空き枠か弱いほうの枠に自動で装備。付け替えで外れたカードと、強くないカードは、**その場でコイン（売値）と経験値（売値×`sellExpPerCoin`＝20）に還元**。持ち物は最大8枚で、枚数の上限は不要になった（`MemoryCardService.Pull`）。 |
| 経験値 | **リーダー強化を150Lvまで**延長（Lv51〜150は1Lvあたり+100％）。Lv50 までは1.12倍ずつ、Lv50 以降は1.06倍ずつ重くなる（`lateFromLv`・`lateExpGrowth`）。魔力の欠片はLv50 以降は増えない（経験値だけが重い）。 |
| 星の砂 | 霊石版の最大Lvを20→40に。Lv20 を超えると、1Lvごとに星の砂の費用が×1.15（`levelCostGrowthFromLv`・`levelCostGrowth`）。 |
| ワイン | タロットの入れ替えのたびに費用が上がる：費用 ＝ レアの基準 ×（1 ＋ これまでの入れ替え回数 × 0.25）（`TarotService.Cost`、セーブの `research.tarotChanges`）。さらに上のレアを3つ足した（EX+・XR・XR+。ワイン 77.8万・233万・700万）。 |
| コイン | 新ツリー「金庫の研究」（`vault`、コインで払う。攻撃・HP・防御を20ノード×5Lvずつ、費用は第k ノード = 7,000万×k ×（1＋Lv））。 |
| 研究メモ | 新ツリー「深層研究」（`deep`、研究メモで払う。同じ形で、費用は 300×k）。 |
| 覚醒の欠片 | ★12〜16 の必要枚数を50倍（400・450・500・550・600。合計96→2,546）。 |

ツリーのノード・費用は JSON だけの変更。View の箱庭に「深層研究」「金庫の研究」の行を足した。

## 追記：絆ハートのまとめ引き（2026-11-17）
ユーザーの指示：元のゲームでは1回に最大20回引けるが、100・250・500・1000回も、進捗で解放して使えるようにしたい。

- `memory_cards.json` の `pullCounts`（20・100・250・500・1000）。20 は記憶カードの解放（ランク2）から、100＝ランク8、250＝ランク16、500＝ランク26、1000＝ランク36 で解放（`unlocks.json` の `memory_pull_N`）。
- `GameSession.PullMemoryCards(count)`：途中で止まらず引き切る（強いカードは装備、それ以外はその場でコインと経験値に還元）。絆ハートが尽きたらそこまで。`GameState.MemoryPullCounts` が、いま使える回数。箱庭に回数ごとのボタンを追加。
- 遊び手は、いま使える最大の回数で引く。通しの検証（1日1時間）：最終ボスは140日目、絆ハートの使用率は36％→58％（強くなるカードが出なくなると遊び手は止める）。

## 追記2：自動交換をやめて「確認つき」に（2026-11-17）
ユーザーの指示：まとめ引きは「自動で回り、絆ハートが尽きるまで（または回数まで）引き切る。止められる」。強いカードが出たら自動で交換せず、**確認を出す**（既定）。確認なしで交換するモードは捨てる。強さだけでなく、**レア以上・サブ効果の絞り込み**で条件を決めて、合ったカードを確認させる。

- 引いたカードが「確認の条件」に合えば、**返事待ち**（`memory.pending`、保存される）にして止まる。合わないカードは、その場でコインと経験値に還元（溜まらない）。返事待ちがある間は新しく引けない（`HasPending`）。
- 返事：`GameSession.ResolveMemoryCard(equip, slot)`。交換する＝装備（枠を指定しなければ、同じ種類の空き枠か弱いほうの枠。外れたカードは還元）、交換しない＝そのカードを還元。
- 条件：`SetMemoryRule`（`memory.rule`。レアの順番以上・サブ効果の絞り込み2組（各2つまで）・いまより強いこと［既定オン］。全部満たしたカードが対象）。
- まとめ引き（20・100・250・500・1000）：`PullMemoryCards(count)`。確認が出たところで止まる。View は答えたあと、残りの回数ぶん続きを引く。「やめる」で止められる（返事待ちは残る）。
- 画面：ガチャのハブに「記憶カード」を追加（`MemoryScreen`：まとめ引き・確認の表示（いま付けているカードとの比較）・条件の変更）。箱庭の引くボタンは移した。
- 遊び手（`EconomyBot`）は、確認が出たら毎回「交換する」で答える（以前の自動交換と同じ結果。通しの検証：最終ボス159日目）。
- 削除：`AutoPullMemoryCard`（旧・自動絆ガチャ）、確認なしで装備する経路。
