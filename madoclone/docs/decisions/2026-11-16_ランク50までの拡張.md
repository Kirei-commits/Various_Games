# ランク50までの拡張（2026-11-16、ユーザー依頼）

依頼：最終ボスまで100日以上かかってよい（365日でもよいが、エンドコンテンツすぎるので、ランク50ぐらいまで）。そこまで強くなって倒せるように、他の育成も含めて検討し直す。通しの検証（e2e）は1年かかってもよい。

## 決めたこと
- **ランクは50まで**（`difficulty.json` の `ranks`）。ランク33〜50 の敵の伸び率 g は 1.20 → 1.08（線形）。最終ボス（`finalBossTraits`・180秒）はランク50の 10-10 に移った。ランク29〜50 のボスの特徴は同じ4つ（クリ・命中・解除・怒り）。
- **限界突破（自作の終盤の育成）**：★12〜★16 と Lv 上限 200 を足した。
  - ★12〜16 の最大 Lv：135・150・165・180・200。星の倍率：7.5・8.5・9.5・10.5・11.5（★11 は 6.5）。覚醒に要る欠片：8・9・10・11・12（★0〜11 は元の46枚のまま、全体で96枚）。
  - Lv121〜200 の基礎ステータスと経験値は、Lv120 の伸び率（約2.5％/Lv）を Lv に反比例させて減らしながら外挿（`measured: false`）。Lv200 の基礎は Lv120 の約4.6倍。
  - 図鑑の目標は★ごとに増えるので、全達成の上限が 5,000％ → 約 6,200％ になった（テストの上限を直した）。
- ランク1〜32の校正（標準倍率・敵の倍率）は変えていない（ゴールデンも不変）。ランク32だけ、最終ボスではなくなったので校正し直した。ランク33〜50 は `calibrate` で求めた（ボス勝率 79〜81％、推奨の70％で勝率 5％以下）。標準編成の★・Lv は、ランク33〜34＝★12、35〜38＝★13、39〜42＝★14、43〜46＝★15、47〜50＝★16。

## 通しの検証（e2e）の結果
`scripts/e2e.sh [1日の時間×10] [日数]`（チェックポイント付き。止まっても続きから再開できる）。本物の育成だけで遊ぶ遊び手（霊石版・タロット・竜の巣・広場・研究・記憶カードの自動絆ガチャ・交換所・サポートまで使う）。
- **1日1時間**：ランク20＝32日、32＝84日、40＝111日、48＝151日、**最終ボス撃破＝221日目**。
- **1日2時間**：ランク20＝20日、32＝78日、40＝87日、48＝125日、**最終ボス撃破＝178日目**。
- つまり、完璧に遊ぶ遊び手で約半年。実際の遊び手はもっと遅いので、1年前後の見込み（依頼の範囲）。
- ランク24〜32 に時間がかかり、36以降は速い（Lv が上限に近づき、限界突破の効果が出る）。ここはなだらかにしたいなら、ランク33〜40 の g を上げる。

- 図鑑の効果の計算結果をキャッシュした（目標の一覧が変わったときだけ再計算）。
