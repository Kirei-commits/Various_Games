# 2026-11-15 実装の最初の一歩（骨組みと乱数）

ユーザー指示：「実装をちょっとずつ始めて」。

## やったこと

- asmdef を4本置いた：`Mado.Data`／`Mado.Core`（ともに `noEngineReferences`）、`Mado.View`、`Mado.Core.Tests`（Editor）。
- dotnet 用に `tools/Mado.CoreLib`（Core と Data のソースを取り込む netstandard2.1・C# 9、警告をエラー扱い）と `tests/Mado.Core.Tests`（net8.0、NUnit）を置いた。実装編の「Core・Data を取り込むライブラリ」を、1つの独立したプロジェクトにした。
- 乱数 `Rng`（xoshiro128**）と `SplitMix64` を `Assets/Game/Core/Util` に作り、テスト `RngTests` を書いた。
- 乱数の期待値は、Python の参照実装 `tools/bootstrap/rng_reference.py` が作る（SplitMix64 は公開されている既知の出力と一致することを確かめてある）。
- `tools/bootstrap/check_sources.py`：Core・Data のソースに UnityEngine・System.Random・DateTime.Now、向きの違う名前空間の参照が無いかを文字列で調べる。`scripts/check.sh` から呼ぶ。
