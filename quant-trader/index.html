Quant Backtester

戦略・リスク管理・手数料を変えて、バックテストの成績を比べられます。中身は quant-trader/quant の Python コードそのもので、ブラウザ内（Pyodide）で動きます。

設定

列: Date, Open, High, Low, Close, Volume（Yahoo Finance の形式でそのまま読めます）
Python を読み込んでいます…（初回は 10〜30 秒ほど）

資産の推移

成績

Sharpe・Sortino は年率換算。PF＝総利益÷総損失。DD＝最大ドローダウン。露出＝ポジションを持っていた時間の割合。
