# 練習銀行アカデミー（仮称）

新卒〜中堅のエンジニアが、基礎力を失わずに **AI前提の開発プロセス（仕様 → AI実装 → 検証 → 運用）** を段階的に身につけるための練習アプリです。
架空の銀行アプリ「練習銀行」を、単元を進めながら自分のリポジトリで育てていきます。

仕様の出典は「アプリ開発練習アプリ 仕様プロンプト v0.1」。実装上の判断・要件との対応・未決事項は [SPEC-NOTES.md](./SPEC-NOTES.md) にあります。

## 遊び方

`index.html` をブラウザで開くだけです（サーバー不要・実行時の依存ゼロ）。GitHub Pages でも公開します。

1. **オンボーディング** — 5問の自己評価から、開始レベルと最初の単元を提案
2. 単元ごとに同じ5ステップ（L3 は実践ステップの進め方が変わる。下の表を参照）
   1. **理解（AIオフ）** 概念を読み、予測問題に答える
   2. **練習（AIオフ）** パーソンズ → 穴埋め → 修正 → ゼロから、の4段階。テストが通るまで
   3. **説明ゲート** 「何をするか」「どこが危ないか」を書く。合格すると AI が解禁
   4. **実践（AIオン）** 仕様を書いて AI に実装させ、差分をレビューし、テストで検証。説明してから取り込み、コミット → PR → CI → マージ
   5. **振り返り** AIオフ／オンの所要時間・失敗数・ヒント数・質問数を、事前の体感と並べて見る
3. マージしたコードはホームの「練習銀行」（スマホの銀行アプリ風の画面）で実際に動き、銀行が育っていきます。AI の解禁・マージ・修了ではお祝いの演出と効果音（設定で切れる。失敗では鳴らない）

## 収録している単元

| レベル | 単元 |
|---|---|
| L1 新卒入門 | L1-01 金額を円で表示する ／ L1-02 残高を計算する ／ L1-03 ユーザーストーリーと受け入れ基準 ／ L1-04 単体テストを読み書きする ／ L1-05 小さなコミットとPR ／ L1-06 計算と表示を分ける ／ L1-07 秘密情報を画面やログに出さない ／ L1-08 ログを読む ／ L1-09 情報区分とAI利用ルール ／ L1-10 答えを写さずに質問する |
| L2 独り立ち | L2-01 AIなしでバグを直す ／ L2-02 入力を検証する ／ L2-03 二重送金を防ぐ ／ L2-04 AIが書いたPRの欠陥を見つける ／ L2-05 SQLインジェクションとXSSを理解する ／ L2-06 データを正規化する ／ L2-07 小さなPRに分けて、戻せるようにする ／ L2-08 障害の原因を特定する ／ L2-09 タスクを分解し、AIの差分を検証する ／ L2-10 LLMの出力を構造化して受け取る |

| L3 チームの中核（第2段階） | L3-01 仕様からAIに実装させる（振込予約）／ L3-02 AIのPRを本気でレビューする ／ L3-03 FAQボットへのプロンプトインジェクション ／ L3-04 リトライと縮退運転を設計する ／ L3-05 SLOとエラーバジェット |

L1・L2 で11領域のうち A〜K のすべてに単元があります（L1 は I を除く10領域）。

L3 の実践ステップは進め方が変わります。
- **spec-first ミッション**（L3-01・04・05）: EARS 記法の要件（自動判定）→ 設計を選ぶ → タスクに分ける → 要件IDつきのテスト → AI 実装 → 要件とテストの対応表（テストの無い要件を警告）
- **PR レビュー**（L3-02）: 欠陥を埋め込んだ AI の PR で、欠陥のある行を指摘して検出率で採点 → 直して取り込む
- **赤チーム演習**（L3-03）: 架空の FAQ ボットにプロンプトインジェクションを試し、入力・出力の両方で守る

「ダッシュボード」では、単元をまたいで AIオフ／オンの所要時間・失敗・ヒント・質問を比べられます。

## AIチューター

- 標準は **ルールベースの疑似チューター**（無料・オフライン）。答えやコードは出さず、質問とヒントで導きます
- 設定で Claude の API キーを入れると、チューター・AI実装・説明の観点採点が本物の LLM（既定 Claude Opus 5.5、月の上限を超えたら Claude Haiku 5.5）になります
- AIへ送る前に、メールアドレス・電話番号・口座番号・カード番号・APIキーの形式を検査し、見つかったら送信を止めます
- AI の入出力はすべて「AI利用ログ」にハッシュの鎖つきで記録され、改ざんを検証できます

## 開発

```bash
npm ci
npm run lint        # 構文・読み込み順・外部参照・CSP・純粋なモジュール
npm run test:logic  # コンテンツ・採点・Git・チューター・評価セット（Node の標準テスト）
npm run test:e2e    # Playwright（デスクトップ + スマホ）
```

ブラウザを取得できない環境では `PW_CHROMIUM=/path/to/chrome npm run test:e2e`（リポジトリ直下の LOOP.md 参照）。
