# 仕様メモ — 練習銀行アカデミー

出典: 「アプリ開発練習アプリ 仕様プロンプト v0.1」（2026-10-15）。この文書は、実装にあたっての判断・要件との対応・新しく見つかった未決事項の記録です。

## 1. オーナーに確認して決めたこと（2026-10-16）

| 論点 | 決定 | 仕様上の位置づけ |
|---|---|---|
| Q-01 誰に提供するか / Q-02 提供形態 | 個人学習＋少人数パイロット向けの **静的 Web アプリ**（このリポジトリ、GitHub Pages） | 推奨どおり |
| Q-03 AI の実行場所 | 標準は **ルールベースの疑似チューター**（無料・オフライン）。学習者が Claude の API キーを入れたら LLM | 推奨（併用）を、まずクラウドのみで |
| Q-04 課題の言語 | **JavaScript**（TypeScript はコンパイラの読み込みが要り、依存ゼロと衝突するため）。型は JSDoc で示す | 推奨から変更。TS は第2段階で |
| Q-05 サンドボックス | **ブラウザ内**（使い捨ての Web Worker ＋ CSP でネットワーク遮断） | 未定 → 決定 |
| Q-06 説明ゲートの採点 | **併用**: 必須観点のルール採点。API キーがあれば LLM の観点採点を上乗せ | 推奨どおり |
| Q-08 Git サンドボックス | **独自の簡易版**（ブランチ・コミット・PR・CI・3方向マージ・リバート） | 推奨どおり |
| Q-09 メンター機能 | MVP には入れない（共有フラグだけ持つ） | 推奨どおり |
| AIオフ中のチューター（4.2 と 6・8章の矛盾） | **AIオフ中も質問のみ10回まで使える**。コード生成・補完はAIオフ中は使えない | 6章・8章を優先。FR-011 と受け入れ基準の該当行は下の「変更履歴」で読み替え |
| ゲームとしての要素 | **練習銀行が育つ演出**: main にマージしたコードを、ホームでその場で動かして見せる | スコア公開・ランキングは C-06・スコープ外で入れない |
| 範囲 | MVP 全部（L1×5・L2×5、8画面、FR-001〜053） | 4章 |

## 2. 解釈して決めたこと（仮説）

| 項目 | 解釈 | 理由 |
|---|---|---|
| FR-021「同じ段階で2回連続で正解」 | 同じ段階の問題を続けて2問解けたら次の段階を提案。途中で落ちても数え直さない（やり直し扱い） | C-06（失敗を罰にしない）と両立させるため。次の段階へはいつでも進める |
| 練習の問題数 | パーソンズ・穴埋め・修正は各2問、ゼロからは1問 | FR-021 の「2回連続」を成り立たせる最小数 |
| FR-014 取り込み時の説明 | 未入力（10文字未満）のときだけ拒否。観点の不足は助言として返す | 仕様の文言が「未入力なら拒否」のため。採点は説明ゲート（FR-012）で行う |
| 説明ゲートの対象 | 自分のゼロから解答、またはお手本コード（切り替え可） | 3章の基本ループの文言どおり |
| AIオン課題の「AIの実装」 | API キーが無いときは、仕様の網羅度で2種類の下書き（境界まで書けていれば正しい版、足りなければ「ほぼ正しい」版）を返す練習用の実装役 | 「仕様の書き方で AI の出力が変わる」を API なしでも体験させるため |
| FR-052 口座番号の形式 | 「口座」「account」などの語の直後の7桁、または「3桁-7桁」 | 単なる7桁の数字は金額（1000000 など）と区別できないため。題材の架空の口座番号（引用符つきの7桁）は止めない |
| 計測の時間 | 単元の画面（とその単元の実践中のリポジトリ画面）を表示していた時間だけ | 体感と比べるための「作業時間」として |
| FR-040 リポジトリの作成時点 | 最初の単元を開いたとき（L1 以外から始めても作る） | L2 から始めた学習者も実践で使うため |

## 4. 静的 Web 版では満たせない・未対応の要件

| 要件 | いまの状態 | 本番で必要なこと |
|---|---|---|
| NFR-01 CPU 1コア・メモリ 512MB の上限 | 時間（5秒）だけ制限。メモリはブラウザ任せ | サーバー側コンテナで実行（Q-05 の再検討） |
| NFR-02 SSO・パスキー・MFA | 認証なし（端末ローカル） | 利用者の管理を始めるときに |
| NFR-05 改ざん検知・1年保持 | ハッシュの鎖で改ざん検知はできるが、保存先は学習者のブラウザ | サーバー側の追記専用ストレージ |
| NFR-07 学習に使われない API 契約 | 設定画面で確認を促すだけ | 組織として契約・設定を確認 |
| NFR-08 稼働率・NFR-10 SLO | 対象外（静的配信） | サーバーを持つとき |
| NFR-13 カバレッジ・SAST を必須ゲートに | lint・ロジック・E2E は CI の必須。カバレッジ・SAST は未導入 | 第2段階で |
| 9章 E2E「AIオフで生成・補完が使えない」 | 生成・補完が無いことを E2E で確認。チューターは決定どおり回数つきで使える | — |
